# 限价单最优挂单价格研究 (Optimal Limit Order Placement)

## 研究背景

本系统的核心场景：使用 GARCH 模型预测下一根 K 线的价格区间 [low, high]，在信号方向（做多/做空）确定后，需要数学地确定该区间内的最优限价单挂单价格。

核心权衡：**成交概率 (fill probability)** vs **入场价格质量 (price improvement)** -- 挂单越靠近区间边界，价格越优但成交概率越低；越靠近中间价，成交概率越高但价格优势越小。

## 方法一：Avellaneda-Stoikov 做市模型 (2008)

### 来源
- Avellaneda, M., & Stoikov, S. (2008). "High-frequency Trading in a Limit Order Book." *Quantitative Finance*, 9(2), 127-137.
- 引用量：1200+

### 核心数学模型

该模型通过两个关键公式确定最优报价：

**预留价格 (Reservation Price)**：

```
r(s, t, q) = s - q * gamma * sigma^2 * (T - t)
```

其中：
- `s` = 当前中间价 (mid-price)
- `q` = 当前库存量 (正为多头，负为空头)
- `gamma` = 风险厌恶系数 (risk aversion / inventory risk parameter)
- `sigma` = 波动率
- `T - t` = 距离收盘的剩余时间
- `r` = 预留价格 (inventory-adjusted fair value)

**最优价差 (Optimal Spread)**：

```
delta* = gamma * sigma^2 * (T - t) + (2/gamma) * ln(1 + gamma/kappa)
```

其中：
- `kappa` (kappa) = 订单簿流动性参数，与市场订单到达率相关
- 到达率模型：`lambda(delta) = A * exp(-kappa * delta)`，delta 为距中间价的距离

**最优挂单价格**：

```
bid* = r(s, t, q) - delta*/2
ask* = r(s, t, q) + delta*/2
```

### 成交概率函数

限价单的成交概率与距中间价的距离呈指数衰减关系：

```
P(fill | delta) = 1 - exp(-A * exp(-kappa * delta) * dt)
```

- `A` = 到达率常数（单位时间内市场订单到达的基础频率）
- `kappa` = 衰减系数（订单簿深度/流动性指标）
- `delta` = 限价单距参考价的距离
- `dt` = 订单暴露时间

### 适用于 GARCH 场景的推导

给定 GARCH 预测区间 [low, high] 和信号方向：

**做多场景** (买入限价单)：

```
sigma_predicted = (high - low) / (2 * z_alpha)  -- GARCH 预测波动率
mid_price = (best_bid + best_ask) / 2

-- 方法一：直接映射到区间
bid_optimal = r(mid, t, q) - delta*/2

-- 映射到 [low, high] 区间
-- 如果 bid_optimal < low，则挂单价 = low（最保守边界）
-- 如果 bid_optimal > high，则信号本身可能无效
-- 正常情况：bid_optimal 落在 [low, mid_price] 区间内
```

**做空场景** (卖出限价单)：

```
ask_optimal = r(mid, t, q) + delta*/2

-- 正常情况：ask_optimal 落在 [mid_price, high] 区间内
```

**关键洞察**：A-S 模型的最优挂单价由 `r +/- delta*/2` 决定，其中 `sigma` 来自 GARCH 预测。这意味着：

1. GARCH 预测的 `sigma` 越大 --> 价差 `delta*` 越宽 --> 挂单价越远离中间价
2. `gamma` 越大（风险厌恶越高）--> 价差也越宽
3. `kappa` 越大（流动性越好）--> 价差越窄

### 实际工程化参数

从 Hummingbot 的生产实现中提取的关键参数：

```
-- 交易强度参数 (Trading Intensity)
alpha = 基础到达率，从订单簿历史数据估算
kappa = 衰减率，从订单簿历史数据估算

-- 波动率计算
使用 InstantVolatilityIndicator 实时计算

-- 最终报价
optimal_bid = reservation_price - optimal_spread / 2
optimal_ask = reservation_price + optimal_spread / 2

-- 预留价格调整（基于库存目标偏差）
inventory_distance = current_inventory_pct - target_inventory_pct
reservation_price = mid_price - inventory_distance * risk_factor * sigma^2 * time_remaining
```

## 方法二：Gueant-Lehalle-Tapia 扩展模型 (2011/2012)

### 来源
- Gueant, O., Lehalle, C.-A., & Tapia, J.F. (2012). "Dealing with the Inventory Risk. A solution to the market making problem." *Mathematics and Financial Economics*, 7(4), 477-507.
- arXiv: 1105.3115

### 核心数学模型

该论文将 A-S 模型的 HJB (Hamilton-Jacobi-Bellman) 方程转化为线性常微分方程组，并提供**封闭形式的渐近近似解**。

**最优报价渐近公式**：

```
delta_bid(q) = 1/gamma * ln(1 + gamma * A/gamma / kappa) + (1/kappa) * [(2*q+1) * gamma * sigma^2 * (T-t)/2 - ...]
delta_ask(q) = 1/gamma * ln(1 + gamma * A/gamma / kappa) + (1/kappa) * [(-2*q+1) * gamma * sigma^2 * (T-t)/2 - ...]
```

关键改进：
- 报价不仅是库存 q 的函数，还显式包含了谱分解 (spectral decomposition) 特征
- 渐近行为：当 T-t 很大时（长期限），报价趋向于稳定值
- 当 gamma 趋近于 0 时，退化为对称报价（bid/ask 关于中间价对称）

**到达率模型 (同 A-S)**：

```
lambda_buy(delta) = A * exp(-kappa * delta)
lambda_sell(delta) = A * exp(-kappa * delta)
```

### 适用于 GARCH 场景

该模型的参数化更强，关键优势是提供了**可计算的封闭形式解**：

```
-- 给定 GARCH 预测
sigma_garch = GARCH_predicted_volatility
[low, high] = GARCH_predicted_range

-- 计算最优偏移量
delta_bid = compute_GLMT_bid_offset(q, gamma, sigma_garch, kappa, T_minus_t)
delta_ask = compute_GLMT_ask_offset(q, gamma, sigma_garch, kappa, T_minus_t)

-- 最优挂单价
optimal_buy_limit = mid_price - delta_bid
optimal_sell_limit = mid_price + delta_ask

-- 约束到 [low, high] 区间
optimal_buy_limit = clamp(optimal_buy_limit, low, mid_price)  -- 做多
optimal_sell_limit = clamp(optimal_sell_limit, mid_price, high)  -- 做空
```

## 方法三：Cartea-Jaimungal 框架 (2015)

### 来源
- Cartea, A., & Jaimungal, S. (2015). "Optimal Execution with Limit and Market Orders." *Quantitative Finance*, 15(1), 63-77.
- Cartea, A., Jaimungal, S., & Penalva, J. (2015). *Algorithmic and High-Frequency Trading.* Cambridge University Press.

### 核心数学模型

该框架统一处理了限价单和市价单的最优执行问题，使用**随机控制**方法。

**限价单成交概率模型**：

```
P(限价单在 dt 内成交 | 距参考价距离为 delta) = lambda(delta) * dt

lambda(delta) = {
    A * exp(-kappa * delta)      -- 指数衰减模型（主流）
    A * (1 + kappa * delta)^(-alpha)  -- 幂律衰减模型
}
```

**最优执行目标函数**：

```
sup_{delta^+, delta^-} E[ integral_0^T (
    - delta^+(t) * lambda(delta^+(t))  -- 卖出限价单的收益
    + delta^-(t) * lambda(delta^-(t))  -- 买入限价单的成本节约
    - phi * q(t)^2                      -- 库存惩罚
    - beta * (execution_shortfall)       -- 执行不足惩罚
) dt ]
```

其中 `phi` 是库存惩罚系数，`q(t)` 是当前持仓。

**最优挂单价格公式（有限时间 T）**：

```
delta^+*(t, q) = (1/kappa) * [1 + ln(1 + kappa * g(t) / (1 + kappa * h(t)))]
delta^-*(t, q) = (1/kappa) * [1 + ln(1 + kappa * g(t) / (1 + kappa * h(t)))]
```

其中 `g(t)` 和 `h(t)` 是由 HJB 方程的解给出的时间相关函数。

### 成交概率 vs 价格质量的权衡

Cartea-Jaimungal 框架给出了最清晰的权衡分析：

```
-- 定义：价格改善 = mid_price - limit_price（对买单）
-- 定义：成交概率 = lambda(delta) * dt

-- 权衡函数
V(delta) = price_improvement(delta) * fill_probability(delta)
         = delta * A * exp(-kappa * delta) * dt

-- 最优点（对 V(delta) 求导 = 0）
dV/d(delta) = A * exp(-kappa * delta) * (1 - kappa * delta) = 0
delta* = 1/kappa

-- 即：最优挂单距离 = 1/kappa（与流动性参数反相关）
-- kappa 大（流动性好）--> delta* 小（靠近中间价）
-- kappa 小（流动性差）--> delta* 大（远离中间价）
```

这是一个极其重要的结论：**在不考虑库存风险的情况下，最优挂单距离等于流动性衰减系数的倒数 `1/kappa`**。

### 适用于 GARCH 场景

```
-- Step 1: 从 GARCH 获取预测
sigma_garch = predicted_volatility
[low, high] = predicted_range

-- Step 2: 估算 kappa（从订单簿数据）
-- 方法：统计不同距离处的市场订单到达频率，拟合 lambda(delta) = A*exp(-kappa*delta)
kappa = estimate_from_orderbook(orderbook_history)

-- Step 3: 计算最优偏移
delta_star = 1 / kappa  -- 简化版（无库存风险）

-- Step 4: 考虑库存风险调整
delta_adjusted = delta_star + inventory_risk_adjustment(q, phi, sigma_garch)

-- Step 5: 映射到 [low, high]
-- 做多：
buy_price = mid_price - delta_adjusted
buy_price = max(low, min(buy_price, mid_price))

-- 做空：
sell_price = mid_price + delta_adjusted
sell_price = min(high, max(sell_price, mid_price))
```

## 方法四：Cont-Kukanov 凸优化方法 (2017)

### 来源
- Cont, R., & Kukanov, A. (2017). "Optimal Order Placement in Limit Order Books." *Mathematics of Operations Research*, 42(3), 603-634.

### 核心数学模型

该方法将限价单挂单问题建模为**凸优化问题**，目标是在有限时间内以最优价格完成指定数量的交易。

**优化目标**：

```
min E[ Cost(orders) ] + penalty_risk * Risk(orders)

s.t.:
  - 每个价位的订单量 >= 0
  - 总订单量 = target_volume
  - 每个价位的价格在允许范围内
```

**成本函数**：

```
Cost = sum_i ( n_i * p_i + fee_i )
```

其中 `n_i` 是在价位 `p_i` 挂单的数量，`p_i` 是该价位的价格。

**关键约束：成交概率**

```
-- 在价位 p_i 处挂单 n_i 的预期成交量
E[filled_i] = n_i * P(price_reaches_p_i)

-- P(price_reaches_p_i) 可以从 GARCH 预测直接估算
```

### 适用于 GARCH 场景（最直接适配）

该方法是所有方法中与 GARCH 预测区间 [low, high] 适配最直接的：

```
-- 给定 GARCH 预测
[low, high] = predicted_range
signal = LONG or SHORT

-- Step 1: 在 [low, high] 区间内离散化 N 个价位
prices = linspace(low, high, N)  -- e.g., N=20

-- Step 2: 估算每个价位的成交概率
-- 利用 GARCH 预测的分布信息
for p_i in prices:
    if signal == LONG:
        P_fill[i] = P(predicted_low <= p_i)  -- 价格触及该位或以下的概率
    else:
        P_fill[i] = P(predicted_high >= p_i)  -- 价格触及该位或以上的概率

-- Step 3: 设定优化问题
min  sum_i ( n_i * p_i )                        -- 最小化期望成本
s.t. sum_i ( n_i * P_fill[i] ) >= target_fill   -- 确保足够的成交概率
     sum_i n_i = total_order_size                -- 总挂单量
     n_i >= 0

-- Step 4: 求解（凸优化，可用 CVXPY 等工具）
optimal_allocation = solve_convex(C, P_fill, target_fill, total_order_size)
```

**关键公式（成交概率估算）**：

假设 GARCH 预测的价格服从正态分布 `S ~ N(mu, sigma^2)`，区间 [low, high] 为置信区间：

```
-- 做多场景：买入限价在 p 处的成交概率
P_fill_buy(p) = P(S <= p) = Phi((p - mu) / sigma)

-- 做空场景：卖出限价在 p 处的成交概率
P_fill_sell(p) = P(S >= p) = 1 - Phi((p - mu) / sigma)

-- 其中 Phi 是标准正态 CDF
```

**最优挂单价格（单一订单简化）**：

```
-- 做多：最大化 (mid_price - p) * P_fill_buy(p)
-- 即寻找使「价格改善 x 成交概率」最大化的 p

objective(p) = (mid_price - p) * Phi((p - mu) / sigma)

d_objective/dp = -Phi((p-mu)/sigma) + (mid_price - p) * phi((p-mu)/sigma) / sigma = 0

-- 其中 phi 是标准正态 PDF
-- 该方程没有封闭解，但可以用数值方法快速求解
```

## 方法五：Guo-De Larrard-Ruan 解析最优挂单位置 (2017)

### 来源
- Guo, X., De Larrard, A., & Ruan, Z. (2017). "Optimal Placement in a Limit Order Book: An Analytical Approach." *Mathematics of Operations Research*, 42(3), 603-634.

### 核心数学模型

该方法基于 Cont & De Larrard (2013) 的 Markovian 限价单市场模型，推导出最优挂单位置的**解析公式**。

**基础模型 (Cont-De Larrard 2013)**：

价格动态由以下 Markov 链描述：
- 限价单到达率：以一定概率在当前最优价之外挂单
- 市价单到达率：吃掉当前最优价上的限价单
- 取消率：以一定概率撤销已有挂单

**最优挂单位置公式**：

```
-- 限价单在距中间价 delta 处的预期收益
-- 取决于价格在触及 delta 之前先触及 0（中间价移动到反方向）的概率

-- 定义：S = 当前中间价，delta_b = bid 距离，delta_a = ask 距离
-- 定义：p_b = 价格先触及 bid 的概率
-- 定义：p_a = 价格先触及 ask 的概率

-- 最优 bid 位置满足：
E[profit_bid(delta_b)] = delta_b * p_b(delta_b) - adverse_selection_cost

-- 解析最优解（在对称情况下）：
delta* = sqrt(2 * D * tau / pi)

-- 其中：
D = 价格过程的扩散系数 (diffusion coefficient) ≈ sigma^2 / 2
tau = 订单暴露时间
pi = 圆周率
```

### 适用于 GARCH 场景

```
-- 从 GARCH 获取参数
sigma_garch = predicted_volatility_per_interval
tau = K线周期（如 5min, 15min, 1h）

-- 计算扩散系数
D = sigma_garch^2 / 2

-- 最优挂单距离
delta_optimal = sqrt(2 * D * tau / pi)
             = sqrt(sigma_garch^2 * tau / pi)
             = sigma_garch * sqrt(tau / pi)

-- 映射到 [low, high]
-- 做多：
buy_price = mid_price - delta_optimal
buy_price = clamp(buy_price, low, mid_price)

-- 做空：
sell_price = mid_price + delta_optimal
sell_price = clamp(sell_price, mid_price, high)

-- 与 GARCH 预测区间的关系验证
-- delta_optimal 应该 <= (high - low) / 2，否则信号不适用
valid = delta_optimal <= (high - mid_price)  -- 做多时
```

## 方法六：基于波动率的价差计算方法

### 来源
- 多个实践来源汇总，包括 Hummingbot、量化交易实践

### 核心公式

**波动率基础价差法**：

```
spread = k * sigma

-- 其中 k 是经验系数（通常 1.5 ~ 3.0）
-- sigma 是波动率（可来自 GARCH 预测）
```

**库存调整后价差法**：

```
spread_adjusted = spread_base + 2 * gamma * sigma^2 * (T - t) * q

-- q 为库存偏离目标值的量
-- gamma 为风险厌恶系数
```

**Bollinger 带类似方法**：

```
-- 利用 GARCH 预测的 mu 和 sigma 构建"合理价位带"
upper_band = mu + k * sigma
lower_band = mu - k * sigma

-- 做多挂单价 = lower_band（或 lower_band 与 low 的 max）
-- 做空挂单价 = upper_band（或 upper_band 与 high 的 min）
```

**价格改善 vs 成交概率的平衡**：

```
-- 定义效用函数
U(p, signal) = alpha * price_improvement(p) + (1 - alpha) * fill_probability(p)

-- 做多：
U_buy(p) = alpha * (mid_price - p) + (1 - alpha) * Phi((p - mu) / sigma)

-- 最优化：
dU_buy/dp = -alpha + (1 - alpha) * phi((p - mu) / sigma) / sigma = 0

-- 解出 p*:
phi((p* - mu) / sigma) = alpha * sigma / (1 - alpha)
p* = mu + sigma * Phi_inv(alpha * sigma / (1 - alpha))

-- 其中 alpha in [0, 1] 是价格改善的权重
-- alpha = 0: 完全追求成交概率，p* = mu（中间价附近）
-- alpha = 1: 完全追求价格改善，p* = low（区间下界）
```

## 方法七：Lehalle-Mounjid 逆向选择模型 (2017)

### 来源
- Lehalle, C.-A., & Mounjid, O. (2017). "Limit Order Strategic Placement with Adverse Selection Risk." *Market Microstructure and Liquidity*.

### 核心洞察

限价单成交时面临**逆向选择风险 (adverse selection)**：当你的限价单被吃掉时，往往是因为价格正在朝不利的方向移动。

**逆向选择成本模型**：

```
-- 限价单成交后的预期价格移动
E[price_move_after_fill | fill_at_price_p] = -alpha * distance_from_mid * sign_of_fill

-- 即：买单成交后，价格倾向于继续下跌；卖单成交后，价格倾向于继续上涨
-- alpha 通常在 0.3 ~ 0.7 之间（实证值）
```

**调整后的最优挂单公式**：

```
-- 考虑逆向选择后的有效收益
effective_profit(p) = price_improvement(p) - adverse_selection_cost(p)

-- 做多：
effective_profit_buy(p) = (mid - p) * P_fill(p) - alpha * (mid - p) * P_fill(p) * P_adverse(p)

-- 这导致最优挂单价格比不考虑逆向选择时更靠近中间价
-- 因为远离中间价的成交伴随着更大的逆向选择成本
```

### 适用于 GARCH 场景

```
-- GARCH 预测区间 [low, high] 本身包含了对波动方向的预期
-- 如果信号为做多，但 GARCH 预测下行风险较大（low 远离 mid），
-- 则应该将挂单价适当上移（减少逆向选择暴露）

-- 逆向选择调整系数
as_adjustment = alpha_adverse * |low - mid| / (|high - mid| + |low - mid|)

-- 调整后做多挂单价
buy_adjusted = buy_base + as_adjustment * (mid - buy_base)
-- 即在基础挂单价基础上，向中间价方向调整一定比例
```

## 方法八：DeLise 负漂移现象 (2024)

### 来源
- DeLise, T. (2024). "The Negative Drift of a Limit Order Fill." arXiv: 2407.16527

### 核心发现

这是最新的实证研究，揭示了限价单成交的一个关键现象：**限价单成交时伴随着负漂移 (negative drift)**。

**核心结论**：
- 理论模型假设限价单成交是"低成本随机事件"
- 实证发现：限价单成交与不利价格移动高度相关
- 在 10 年期美国国债期货上的实证验证

**负漂移的度量**：

```
-- 限价单成交后的价格漂移
drift_post_fill = E[S(t + dt) - S(t) | fill_at_t]

-- 理论期望（对称情况）: 0
-- 实证观察: < 0（对买限价单成交后价格继续下跌）

-- 负漂移强度
negative_drift_intensity = |drift_post_fill| / sigma
```

### 对挂单策略的启示

```
-- 负漂移意味着"远离中间价"的挂单虽然价格更优，但成交时往往是因为价格趋势
-- 对策：在 GARCH 预测区间内，不应过度追求极端价格

-- 建议的调整
optimal_price_adjusted = base_optimal * (1 + drift_correction)

-- drift_correction > 0 表示向中间价方向调整
-- drift_correction 的具体值需从历史数据中估算
```

## 综合方案：适配 GARCH 预测区间的最优挂单框架

基于以上 8 种方法的研究，以下是适配本系统场景的综合框架。

### 输入

| 参数 | 来源 | 说明 |
|------|------|------|
| `[low, high]` | GARCH 预测 | 下一根 K 线的价格区间 |
| `mu` | GARCH 预测 | 预测均值（通常为当前价） |
| `sigma` | GARCH 预测 | 预测波动率 |
| `signal` | 信号系统 | LONG 或 SHORT |
| `q` | 持仓系统 | 当前库存偏离 |
| `kappa` | 订单簿分析 | 流动性衰减系数 |
| `alpha` | 历史数据 | 逆向选择系数 |

### 算法流程

```
Step 1: 参数准备
    sigma_garch = GARCH.volatility_forecast()
    [low, high] = GARCH.range_forecast()
    mid = current_mid_price()
    kappa = estimate_kappa(orderbook_history)
    q = inventory_deviation()

Step 2: 计算预留价格 (A-S 模型)
    r = mid - q * gamma * sigma_garch^2 * time_remaining

Step 3: 计算最优偏移 (多种方法可选)

    -- 方法 A: Cartea-Jaimungal 简化
    delta_base = 1 / kappa

    -- 方法 B: Guo 等人解析法
    delta_base = sigma_garch * sqrt(tau / pi)

    -- 方法 C: A-S 完整公式
    delta_base = (gamma * sigma^2 * (T-t) / 2) + (1/gamma) * ln(1 + gamma/kappa)

Step 4: 库存风险调整
    delta_adjusted = delta_base + abs(q) * gamma * sigma_garch^2 * time_remaining

Step 5: 逆向选择调整
    delta_adjusted -= alpha_adverse * delta_adjusted * (1 - fill_quality_score)

Step 6: 负漂移调整 (DeLise 2024)
    delta_adjusted *= (1 + drift_correction_factor)

Step 7: 约束到 [low, high] 区间
    if signal == LONG:
        optimal_price = mid - delta_adjusted
        optimal_price = clamp(optimal_price, low, mid)
    else:
        optimal_price = mid + delta_adjusted
        optimal_price = clamp(optimal_price, mid, high)

Step 8: 成交概率验证
    P_fill = Phi((optimal_price - mu) / sigma_garch)  -- 做多
    -- 或
    P_fill = 1 - Phi((optimal_price - mu) / sigma_garch)  -- 做空

    if P_fill < min_fill_threshold:
        -- 降低价格改善要求，提高成交概率
        optimal_price = adjust_for_min_fill(optimal_price, min_fill_threshold)

Step 9: 输出
    return optimal_price, P_fill, expected_price_improvement
```

### 成交概率 vs 价格改善的权衡量化

```
-- 定义权衡曲线
-- 横轴：成交概率 P_fill (0 到 1)
-- 纵轴：价格改善 PI = |mid - optimal_price| / sigma

-- 有效前沿 (Efficient Frontier)
-- 对每个 P_fill，计算最大价格改善
PI_max(P_fill) = sigma * Phi_inv(1 - P_fill)  -- 做多

-- 最优操作点（权衡参数 lambda in [0, 1]）
maximize: lambda * PI(p) + (1 - lambda) * P_fill(p)

-- lambda = 0.5 时的解析解（近似）
p* = mu - sigma * Phi_inv(0.5 + lambda/2)  -- 做多
```

### 推荐的工程实现优先级

| 优先级 | 方法 | 复杂度 | 数据需求 | 推荐理由 |
|--------|------|--------|----------|----------|
| P0 | Cartea-Jaimungal 简化法 (`delta = 1/kappa`) | 低 | 订单簿历史 | 简单、直接、有理论基础 |
| P0 | 波动率基础价差法 (`spread = k * sigma`) | 低 | GARCH 输出 | 最易实现，直接使用 GARCH |
| P1 | A-S 预留价格 + 最优价差 | 中 | 订单簿 + 库存 | 生产验证（Hummingbot）|
| P1 | Cont-Kukanov 凸优化 | 中高 | 订单簿 + GARCH | 最直接适配 [low, high] |
| P2 | Guo 解析最优位置 | 中 | GARCH + 时间 | 封闭解，计算快 |
| P2 | 逆向选择调整 | 中 | 历史成交数据 | 提升实际表现 |
| P3 | 负漂移调整 | 低 | 历史成交数据 | 最新研究，锦上添花 |
