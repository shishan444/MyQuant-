## 一、决策树方案: 具体参数建议

### 1.1 方案概述

使用 scikit-learn 的 DecisionTreeClassifier 预测"上涨/下跌/横盘"三分类，
或 DecisionTreeRegressor 预测未来 N 根 K 线的价格变动幅度。

核心优势: 训练后可直接可视化树结构，每个决策节点对应一个指标条件，
天然适合作为"模式发现引擎"--从树结构中提取交易规则，注入到现有 DNA 进化框架。

### 1.2 特征工程: 对接现有指标体系

当前系统已有 30 个指标、6 个类别、预计算输出约 60+ 列。
决策树的特征选择策略:

| 优先级 | 特征来源 | 具体列 | 说明 |
|--------|----------|--------|------|
| P0 | momentum(9) | rsi_7, rsi_14, rsi_21, macd_12_26_9, macd_histogram_12_26_9, stoch_k_14_3, stoch_d_14_3, cci_20, roc_12, willr_14, cmo_14, trix_12 | 超买超卖类，直接反应短期动能 |
| P0 | volatility(4) | bb_upper_20, bb_middle_20, bb_lower_20, atr_14 | 波动率与布林带位置 |
| P1 | trend(6) | ema_10, ema_20, ema_50, sma_20, sma_50 | 趋势方向判定 |
| P1 | volume(8) | rvol_20, vroc_14, obv, cmf_20, mfi_14, cvd | 量能确认 |
| P2 | trend_strength(2) | adx_14, psar | 趋势强度过滤 |
| 衍生 | price_vs_indicator | close/ema_20, close/bb_upper, rsi/70, rsi/30 | 归一化价格相对位置 |

**关键点**: 决策树不需要特征标准化，天然处理混合量纲。
但对高基数特征（如绝对价格、绝对成交量）应转换为相对值（比率、百分比），
避免树过度依赖某一特征。

### 1.3 标签构造

```
预测目标: 未来 forward_period 根K线的收益率

forward_period 建议:
  1h -> 4~8 根 (4~8小时)
  4h -> 2~6 根 (8~24小时)

标签生成:
  future_return = (close[t+forward_period] - close[t]) / close[t]

  三分类:
    UP    if future_return >  +threshold  (threshold = 0.005 即 0.5%)
    DOWN  if future_return <  -threshold
    FLAT  otherwise

  二分类 (更稳定):
    UP    if future_return > 0
    DOWN  if future_return <= 0
```

### 1.4 核心超参数推荐

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import TimeSeriesSplit, GridSearchCV

# ---------- 基础模型参数 ----------
model = DecisionTreeClassifier(
    max_depth=5,              # 限制深度，防止过拟合。范围 3-7
    min_samples_split=50,     # 内部节点最小样本数。4h框架约 2000 bars/年，
                              # 50 约占 2.5%
    min_samples_leaf=25,      # 叶节点最小样本数。确保统计显著性
    max_features='sqrt',      # 每次分裂只考虑 sqrt(n_features) 个特征
                              # 增加随机性，减少对单一特征的依赖
    ccp_alpha=0.005,          # 成本复杂度剪枝参数
                              # 0 = 不剪枝, 0.01 = 激进剪枝
                              # 0.002-0.01 之间用 GridSearchCV 确定
    class_weight='balanced',  # 处理类别不平衡（横盘通常多于涨跌）
    random_state=42,
)

# ---------- 交叉验证: TimeSeriesSplit ----------
tscv = TimeSeriesSplit(
    n_splits=5,               # 5 折时间序列交叉验证
    gap=4,                    # 训练集和验证集之间的间隔
                              # gap=4 对 4h 框架 = 16 小时，模拟实盘延迟
                              # gap=4 对 1h 框架 = 4 小时
    max_train_size=1000,      # 限制训练窗口大小，避免使用过旧数据
                              # 1000 bars / 4h = 约 166 天
)

# ---------- 超参数搜索空间 ----------
param_grid = {
    'max_depth': [3, 4, 5, 6, 7],
    'min_samples_split': [30, 50, 80, 120],
    'min_samples_leaf': [15, 25, 40, 60],
    'ccp_alpha': [0.001, 0.003, 0.005, 0.008, 0.01],
    'max_features': ['sqrt', 0.5, 0.7],  # sqrt 约 7-8 个特征，0.5 约 5 个
}

grid_search = GridSearchCV(
    model, param_grid,
    cv=tscv,
    scoring='f1_weighted',    # 加权 F1，适合类别不平衡场景
    n_jobs=-1,
    verbose=1,
)
```

## 二、统计分组(条件概率)方案: 实现路径

### 2.1 方案概述

将多维指标状态离散化为有限状态空间，统计每种状态组合下未来收益的条件概率分布。
本质是构建条件概率表 (Conditional Probability Table, CPT)，
回答: "当 RSI<30 且 close<BB_lower 且 volume_spike 时，未来4h上涨的概率是多少?"

### 2.2 离散化策略

```python
import numpy as np
import pandas as pd

# ── 策略一: 领域知识分箱 (推荐) ──
# 利用指标的天然语义区间

DISCRETIZE_RULES = {
    'rsi': {
        'bins': [0, 30, 45, 55, 70, 100],
        'labels': ['oversold', 'low', 'neutral', 'high', 'overbought'],
    },
    'macd_histogram': {
        # 基于符号和趋势
        'transform': lambda x: np.sign(x) * (np.abs(x) > x.std() * 0.5).astype(int),
        'labels': ['neg_large', 'neg_small', 'zero', 'pos_small', 'pos_large'],
    },
    'bb_position': {  # (close - bb_lower) / (bb_upper - bb_lower)
        'bins': [0, 0.1, 0.3, 0.7, 0.9, 1.0],
        'labels': ['below_lower', 'near_lower', 'middle', 'near_upper', 'above_upper'],
    },
    'volume_ratio': {  # close / volume_sma_20
        'bins': [0, 0.5, 0.8, 1.2, 2.0, float('inf')],
        'labels': ['very_low', 'low', 'normal', 'high', 'very_high'],
    },
    'trend': {  # close vs ema_50
        'transform': lambda x: np.where(x > 0, 'above', 'below'),
    },
    'adx': {
        'bins': [0, 20, 25, 40, 100],
        'labels': ['no_trend', 'weak', 'strong', 'very_strong'],
    },
}

def discretize_features(df: pd.DataFrame) -> pd.DataFrame:
    """将连续指标值离散化为有限状态标签。"""
    result = pd.DataFrame(index=df.index)

    # RSI
    result['state_rsi'] = pd.cut(
        df['rsi_14'],
        bins=DISCRETIZE_RULES['rsi']['bins'],
        labels=DISCRETIZE_RULES['rsi']['labels'],
    )

    # BB 位置
    bb_width = df['bb_upper_20_2'] - df['bb_lower_20_2']
    bb_pos = (df['close'] - df['bb_lower_20_2']) / bb_width.replace(0, np.nan)
    result['state_bb'] = pd.cut(
        bb_pos.clip(0, 1),
        bins=DISCRETIZE_RULES['bb_position']['bins'],
        labels=DISCRETIZE_RULES['bb_position']['labels'],
    )

    # Volume
    result['state_vol'] = pd.cut(
        df['rvol_20'],
        bins=DISCRETIZE_RULES['volume_ratio']['bins'],
        labels=DISCRETIZE_RULES['volume_ratio']['labels'],
    )

    # Trend direction
    result['state_trend'] = np.where(
        df['close'] > df['ema_50'], 'above', 'below'
    )

    # MACD direction
    result['state_macd'] = np.where(
        df['macd_histogram_12_26_9'] > 0, 'positive', 'negative'
    )

    # ADX strength
    result['state_adx'] = pd.cut(
        df['adx_14'],
        bins=DISCRETIZE_RULES['adx']['bins'],
        labels=DISCRETIZE_RULES['adx']['labels'],
    )

    return result
```

### 2.3 维度约简: 解决组合爆炸

6 个指标，每个 4-5 个状态 -> 4^6 = 4096 种组合，4h 框架一年约 2000 bars，
多数组合样本不足。

**解决方案: 分层分组策略**

```python
def build_conditional_probability_table(
    states_df: pd.DataFrame,
    labels: pd.Series,
    min_samples: int = 30,
) -> dict:
    """构建条件概率表，采用分层策略避免组合爆炸。

    策略:
      Layer 1: 单指标统计 (6 个表)
      Layer 2: 二指标组合统计 (C(6,2)=15 个表)
      Layer 3: 三指标组合统计 (C(6,3)=20 个表)
      高维组合按需计算，不预计算

    Args:
        states_df: 离散化后的状态 DataFrame
        labels: 未来收益标签 (UP/DOWN/FLAT)
        min_samples: 最小样本数，低于此阈值的组合标记为 low_confidence

    Returns:
        嵌套字典: {组合键: {标签: 概率, 'n_samples': int, 'confidence': str}}
    """
    result = {}
    columns = list(states_df.columns)

    # Layer 1: 单指标
    for col in columns:
        for state_val in states_df[col].dropna().unique():
            mask = states_df[col] == state_val
            subset = labels[mask]
            if len(subset) < min_samples:
                continue
            probs = subset.value_counts(normalize=True).to_dict()
            result[f"{col}={state_val}"] = {
                **probs,
                'n_samples': len(subset),
                'confidence': 'high' if len(subset) >= 100 else 'medium',
            }

    # Layer 2: 二指标组合 (仅计算高价值配对)
    HIGH_VALUE_PAIRS = [
        ('state_rsi', 'state_bb'),        # 超卖 + 布林带位置
        ('state_rsi', 'state_vol'),        # 超卖 + 放量
        ('state_bb', 'state_vol'),         # 布林带 + 放量
        ('state_trend', 'state_macd'),     # 趋势 + 动能方向
        ('state_rsi', 'state_trend'),      # 超卖/超买 + 趋势
        ('state_vol', 'state_trend'),      # 量能 + 趋势
        ('state_adx', 'state_rsi'),        # 趋势强度 + 超买超卖
        ('state_adx', 'state_bb'),         # 趋势强度 + 波动率位置
    ]

    for col1, col2 in HIGH_VALUE_PAIRS:
        for s1 in states_df[col1].dropna().unique():
            for s2 in states_df[col2].dropna().unique():
                mask = (states_df[col1] == s1) & (states_df[col2] == s2)
                subset = labels[mask]
                if len(subset) < min_samples:
                    continue
                probs = subset.value_counts(normalize=True).to_dict()
                key = f"{col1}={s1} & {col2}={s2}"
                result[key] = {
                    **probs,
                    'n_samples': len(subset),
                    'confidence': 'high' if len(subset) >= 50 else 'medium',
                }

    return result
```

### 2.4 置信度计算

```python
def compute_confidence(n_samples: int, base_rate: float, observed_rate: float) -> dict:
    """计算统计置信度。

    Args:
        n_samples: 样本数量
        base_rate: 基准概率 (无条件概率, 如 P(UP) = 0.4)
        observed_rate: 观察到的条件概率 (如 P(UP|RSI<30) = 0.62)

    Returns:
        dict with confidence metrics
    """
    # Wilson 区间 (适合小样本的二项分布置信区间)
    from math import sqrt
    z = 1.96  # 95% 置信度
    p = observed_rate
    n = n_samples

    denominator = 1 + z**2 / n
    center = (p + z**2 / (2*n)) / denominator
    margin = z * sqrt(p * (1-p) / n + z**2 / (4*n**2)) / denominator

    ci_lower = center - margin
    ci_upper = center + margin

    # 信息增益: 条件概率偏离基准概率的程度
    lift = observed_rate / base_rate if base_rate > 0 else 0

    return {
        'wilson_ci': (ci_lower, ci_upper),
        'ci_width': ci_upper - ci_lower,
        'lift': lift,
        'is_significant': ci_lower > base_rate or ci_upper < base_rate,
    }
```

### 2.5 查询与信号生成

```python
def query_probability(cpt: dict, active_states: dict, label: str = 'UP') -> dict:
    """查询当前指标状态组合的条件概率。

    策略: 优先匹配高维组合，降级到低维组合。

    Args:
        cpt: 条件概率表
        active_states: 当前状态, e.g. {'state_rsi': 'oversold', 'state_bb': 'near_lower'}
        label: 查询的标签

    Returns:
        dict with probability, confidence, matched_rules
    """
    results = []

    # 尝试所有二指标组合
    state_keys = list(active_states.keys())
    for i in range(len(state_keys)):
        for j in range(i+1, len(state_keys)):
            k1, k2 = state_keys[i], state_keys[j]
            v1, v2 = active_states[k1], active_states[k2]
            key = f"{k1}={v1} & {k2}={v2}"
            if key in cpt:
                results.append({
                    'rule': key,
                    'probability': cpt[key].get(label, 0),
                    'n_samples': cpt[key]['n_samples'],
                    'confidence': cpt[key]['confidence'],
                })

    # 降级到单指标
    for k, v in active_states.items():
        key = f"{k}={v}"
        if key in cpt:
            results.append({
                'rule': key,
                'probability': cpt[key].get(label, 0),
                'n_samples': cpt[key]['n_samples'],
                'confidence': cpt[key]['confidence'],
            })

    if not results:
        return {'probability': 0, 'confidence': 'none', 'matched_rules': []}

    # 按维度降序 + 样本数降序排列，取最佳匹配
    results.sort(key=lambda x: (-x['rule'].count('&'), -x['n_samples']))

    return {
        'probability': results[0]['probability'],
        'confidence': results[0]['confidence'],
        'matched_rules': results,
        'best_rule': results[0]['rule'],
    }
```

## 三、三方对比: KNN vs 决策树 vs 统计分组

| 维度 | KNN (K-近邻) | 决策树 (Decision Tree) | 统计分组 (条件概率) |
|------|-------------|----------------------|-------------------|
| **可解释性** | 低。K=5~20 时，无法直观理解"为什么这些邻居被选中"，需额外可视化(t-SNE/UMAP) | **高**。树结构可视化后，每个分支对应一个指标条件，可直接提取为交易规则并注入 DNA 框架 | **最高**。条件概率表天然可解释："RSI<30 + BB下轨 = 62%上涨概率"，交易员可直接理解和验证 |
| **预测精度** | 中等。依赖距离度量选择，高维空间下"维度诅咒"严重；对加密货币非平稳分布敏感 | 中高。单棵树易过拟合，但 ccp_alpha 剪枝 + TimeSeriesSplit 可控制；集成方法(RF/GB)可达较高精度 | 中低。精度受离散化粒度限制；优势不在精度而在可解释性和统计显著性验证 |
| **计算复杂度** | 推理 O(K*N*D)，N=样本数，D=特征维度；每次预测需扫描全量历史数据 | 训练 O(N*D*logN)，推理 O(depth)；预测极快，适合实盘 | 构建 O(N*K)其中 K=组合数，查询 O(1)哈希查找；构建慢但查询极快 |
| **训练速度** | 无显式训练（lazy learning），但需预处理索引(KD-Tree/Ball-Tree) | 快。1000 样本 * 15 特征 < 1 秒；GridSearchCV 5 折约 30 秒 | 中等。单指标和二指标组合约 1-5 分钟；三指标+组合爆炸需谨慎控制 |
| **数据需求** | 大量历史数据填充空间；4h 框架至少 1 年(2000 bars)才能有效 | 中等。500-2000 样本即可训练出有意义的树；样本过少时树过浅无价值 | **最少**。核心依赖足够的状态组合样本数(>30)；但对罕见组合无法给出可靠估计 |
| **特征处理** | 必须标准化(Z-score/Min-Max)；不同量纲特征需加权或 PCA 降维 | **无需标准化**；天然处理混合量纲和缺失值；但高基数连续特征应先分箱 | 必须离散化；离散化策略直接决定结果质量 |
| **过拟合风险** | 中。K 过小时过拟合，K 过大时欠拟合；交叉验证选 K | 高。深度不受限必过拟合；必须 ccp_alpha + min_samples_leaf 控制 | 低。统计方法本身无参数拟合；但离散化边界可能引入前视偏差 |
| **与现有系统集成** | 需新增 KNN 推理模块；输出为预测标签，需转换层对接 executor.py | **最佳**。树的叶节点规则可直接映射为 SignalGene，通过 dna.py 创建 StrategyDNA | 需新增 CPT 查询模块；输出为概率值，需设计阈值转换为 boolean 信号 |
| **增量更新** | 需重建索引或使用近似 NN；不友好 | 需重训整棵树；但训练快(秒级)，可定期重训 | **友好**。新数据只需更新计数器，无需重算全表 |
| **时间序列适配** | 需手动构造滑动窗口特征；不感知时间顺序 | TimeSeriesSplit 原生支持；gap 参数模拟实盘延迟 | 需滚动窗口统计；窗口外数据自然过期 |

## 四、最终推荐方案

### 推荐: 决策树为主, 统计分组为辅

**理由:**

1. **与 DNA 框架的天然契合** (决定性因素)
   - 决策树叶节点 = 交易规则 = SignalGene 集合
   - 不需要设计新的信号表示格式
   - 提取的规则可直接参与进化优化，形成"发现-验证-进化"闭环

2. **可解释性-精度平衡最优**
   - 统计分组可解释性最高但精度有限
   - KNN 精度可能更高但几乎不可解释
   - 决策树在两者之间取得最佳平衡

3. **工程实现成本最低**
   - scikit-learn 原生支持，无额外依赖
   - 训练/推理代码 < 100 行
   - TimeSeriesSplit + ccp_alpha 保证时间序列正确性

4. **统计分组作为补充验证层**
   - 对决策树发现的高置信度规则，用条件概率表交叉验证
   - 如果决策树规则在 CPT 中的 lift < 1.2，标记为可疑规则
   - 两者互补: 决策树发现非线性的多指标交互，统计分组提供概率置信度

### 推荐实施路径

```
Phase 1 (1-2天):
  [决策树] 特征工程 -> 训练 -> 评估 -> 规则提取
  输入: compute_all_indicators() 的增强 DataFrame
  输出: top-10 高置信度规则 + feature_importance 排名

Phase 2 (1天):
  [规则注入] 树规则 -> SignalGene -> StrategyDNA
  将提取的规则封装为 StrategyDNA，
  通过现有 BacktestEngine + WalkForwardValidator 验证

Phase 3 (1天):
  [统计分组] 构建条件概率表
  对 Phase 1 发现的关键指标组合构建 CPT
  交叉验证决策树规则的统计显著性

Phase 4 (可选):
  [集成升级] 单棵树 -> Random Forest / Gradient Boosting
  精度提升后，用 permutation_importance 替代 feature_importances_
  提取最重要的特征组合用于进化搜索空间缩窄
```

## 五、关键技术风险

### 风险 1: 前视偏差 (Look-Ahead Bias)
- **严重性**: 高
- **描述**: 标签构造使用未来数据 (close[t+N])，训练时必须确保特征仅使用 t 时刻及之前的数据
- **缓解**: TimeSeriesSplit + gap 参数；标签列必须在特征列之后构造；特征中不能包含任何未来信息

### 风险 2: 非平稳性 (Non-Stationarity)
- **严重性**: 高
- **描述**: 加密货币市场机制转换频繁(牛/熊/震荡)，历史模式可能失效
- **缓解**: max_train_size 限制训练窗口(约 6 个月)；定期重训(每周/每月)；监控模型预测分布与实际分布的 KL 散度

### 风险 3: 过拟合到特定市场状态
- **严重性**: 中高
- **描述**: 训练数据如果集中在牛市，模型可能学到"一直做多"的伪规则
- **缓解**: 确保训练数据覆盖至少 1 个完整牛熊周期；class_weight='balanced'；使用 WalkForwardValidator 在多个市场状态下验证

### 风险 4: 离散化边界敏感性
- **严重性**: 中
- **描述**: 统计分组方案中，RSI=29.9 和 RSI=30.1 被分到不同组，可能遗漏边界附近的信号
- **缓解**: 使用软边界(重叠分箱)；领域知识分箱优于等宽/等频分箱；决策树方案不受此影响

### 风险 5: 特征多重共线性
- **严重性**: 中
- **描述**: EMA_10/EMA_20/EMA_50 高度相关，决策树可能随机选择其中一个，导致重要性评估不稳定
- **缓解**: 预过滤: 每类指标只保留最相关的 1-2 个变体；使用 permutation_importance 替代 feature_importances_；集成方法中通过 max_features='sqrt' 增加随机性

### 风险 6: 样本量不足的统计结论
- **严重性**: 中
- **描述**: 统计分组的高维组合样本可能不足 30，概率估计不可靠
- **缓解**: 设置 min_samples=30 阈值；Wilson 置信区间替代简单比例；优先使用低维组合

### 风险 7: 规则冲突
- **严重性**: 低
- **描述**: 从决策树提取的多条规则可能在某些市场状态下给出矛盾信号
- **缓解**: 使用 logic_genes (AND/OR) 组合规则；通过 BacktestEngine 回测验证规则组合效果
