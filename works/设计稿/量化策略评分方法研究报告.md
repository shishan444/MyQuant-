# 量化策略评分方法研究报告

## 一、当前做法的问题分析

### 1.1 当前评分体系

当前系统使用 5 个维度对策略进行评分，加权组合为总分（0-100）：

| 维度 | 指标 | 说明 |
|------|------|------|
| 1 | annual_return (年化收益率) | 策略年化回报 |
| 2 | sharpe_ratio (夏普比率) | 风险调整后收益 |
| 3 | max_drawdown (最大回撤) | 最大峰谷跌幅 |
| 4 | win_rate (胜率) | 盈利交易占比 |
| 5 | calmar_ratio (卡尔马比率) | 年化收益 / 最大回撤 |

同时系统使用交易次数惩罚机制：当交易次数过少时，对总评分进行惩罚。

### 1.2 存在的问题

1. **关键维度缺失**
   - 缺少 Sortino 比率：夏普比率对上行波动和下行波动同等对待，但实际交易中只有下行波动是风险。Sortino 比率仅考虑下行偏差，是更准确的风险调整指标。
   - 缺少 Profit Factor（盈亏比）：衡量总盈利与总亏损的比值，是衡量策略盈利能力的直接指标。
   - 缺少波动率指标：策略净值曲线的波动率反映了策略的稳定性。
   - 缺少净值曲线平滑度：收益率曲线的平滑程度反映策略的稳健性。
   - 缺少最大连续亏损次数/金额：反映策略的心理承受极限。
   - 缺少 VaR/CVaR 指标：衡量尾部风险的标准化指标。
   - 缺少交易频率稳定性：交易是否均匀分布在回测期间。

2. **指标冗余问题**
   - annual_return 和 calmar_ratio 存在信息重叠：Calmar = 年化收益 / 最大回撤，已经包含了 annual_return 的信息。同时使用两者会导致收益维度权重过高。
   - sharpe_ratio 和 calmar_ratio 都包含收益信息，同时使用会双重计算收益贡献。

3. **权重分配缺乏依据**
   - 固定权重的合理性未经回测验证
   - 不同市场环境下最优权重可能不同
   - 没有考虑指标之间的相关性

4. **交易次数惩罚机制不够精细**
   - 当前机制为二元惩罚（交易次数低于阈值则惩罚），缺乏渐进过渡
   - 没有考虑交易频率的统计显著性（交易次数少时，统计指标不可靠）
   - 没有区分不同策略类型的合理交易频率

5. **缺乏鲁棒性评分**
   - 没有衡量策略在参数微扰下的表现稳定性
   - 没有衡量策略在不同时间段的表现一致性
   - 没有衡量策略的过拟合风险

## 二、研究发现

### 2.1 行业主流评估维度

#### 2.1.1 收益类指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **年化收益率** (Annualized Return) | ((1+总收益率)^(365/天数)) - 1 | 衡量策略绝对盈利能力 | 保留 |
| **超额收益** (Excess Return) | 策略收益 - 基准收益 | 衡量超越市场的Alpha能力 | 建议纳入 |
| **月均收益** (Average Monthly Return) | 总收益 / 月数 | 消除周期偏差 | 可选 |
| **复合年增长率** (CAGR) | (期末净值/期初净值)^(365/天数) - 1 | 更准确的年化指标 | 可替代年化收益 |

#### 2.1.2 风险调整后收益指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **夏普比率** (Sharpe Ratio) | (Rp - Rf) / sigma_p | 每单位总风险的超额收益 | 保留 |
| **Sortino 比率** | (Rp - Rf) / sigma_downside | 每单位下行风险的超额收益，仅惩罚下行波动 | 强烈建议纳入 |
| **Calmar 比率** | 年化收益 / 最大回撤 | 收益与极端风险的比值 | 保留 |
| **Omega 比率** | 上行势能 / 下行势能（相对阈值） | 全面衡量收益分布优于阈值的部分 | 可选 |
| **Treynor 比率** | (Rp - Rf) / Beta | 系统性风险调整收益（需基准） | 可选 |

#### 2.1.3 风险类指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **最大回撤** (Max Drawdown) | max((peak - trough) / peak) | 极端风险度量 | 保留 |
| **波动率** (Volatility) | 日收益率标准差 * sqrt(252) | 策略净值波动幅度 | 建议纳入 |
| **下行偏差** (Downside Deviation) | 负收益率的标准差 | 仅衡量下行风险 | Sortino 已包含 |
| **Value at Risk** (VaR) | 在置信水平 alpha 下的最大预期损失 | 尾部风险度量 | 建议纳入 |
| **Conditional VaR** (CVaR/ES) | VaR 超出部分的均值 | 超越 VaR 的极端损失期望 | 建议纳入 |
| **最大连续亏损** (Max Consecutive Losses) | 最长连续亏损交易次数 | 心理承受极限指标 | 建议纳入 |
| **最大连续亏损金额** (Max Consecutive Loss Amount) | 连续亏损期间的最大累计亏损 | 实际资金损失极限 | 建议纳入 |

#### 2.1.4 交易质量指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **盈亏比** (Profit Factor) | 总盈利 / 总亏损 | 直接衡量策略盈利能力 | 强烈建议纳入 |
| **胜率** (Win Rate) | 盈利交易数 / 总交易数 | 衡量交易准确性 | 保留 |
| **平均盈亏比** (Avg Win / Avg Loss) | 平均每笔盈利 / 平均每笔亏损 | 单笔交易的回报风险比 | 建议纳入 |
| **期望值** (Expectancy) | (胜率 * 平均盈利) - (败率 * 平均亏损) | 每笔交易的期望收益 | 建议纳入 |
| **最大单笔亏损** (Max Single Loss) | 单笔交易最大亏损比例 | 极端单笔风险 | 建议纳入 |
| **平均持仓时间** (Avg Trade Duration) | 所有交易的平均持仓时间 | 评估策略风格（日内/波段） | 可选 |

#### 2.1.5 稳定性指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **净值曲线 R-squared** | 净值曲线对线性回归的拟合度 | 曲线越接近直线，策略越稳定 | 强烈建议纳入 |
| **月度收益一致性** | 正收益月份数 / 总月份数 | 收益的时间分布均匀性 | 建议纳入 |
| **收益率偏度** (Skewness) | 收益率分布的三阶矩 | 正偏表示大盈利多，负偏表示大亏损多 | 可选 |
| **收益率峰度** (Kurtosis) | 收益率分布的四阶矩 | 厚尾程度，值越大极端事件越多 | 可选 |
| **交易频率稳定性** | 月度交易次数的变异系数 | 交易是否均匀分布 | 建议纳入 |

#### 2.1.6 鲁棒性指标

| 指标 | 计算方式 | 作用 | 是否纳入建议 |
|------|----------|------|--------------|
| **参数敏感度** | 在最优参数周围微调后性能变化率 | 衡量策略对参数的依赖程度 | 强烈建议纳入 |
| **Walk-Forward 比率** | 样本外收益 / 样本内收益 | 衡量过拟合程度 | 强烈建议纳入 |
| **跨期稳定性** | 将回测期间分为多段，计算各段表现的变异系数 | 策略在不同时段的一致性 | 建议纳入 |
| **蒙特卡洛 P 值** | 随机打乱交易顺序后，原始表现排名百分位 | 策略表现是否优于随机 | 建议纳入 |

### 2.2 权重分配研究

#### 2.2.1 Freqtrade 的权重实践

Freqtrade 的 MultiMetricHyperOptLoss 是一个多指标评分函数，其设计思路值得参考：

- 同时优化多个指标：利润、回撤、盈亏比（profit factor）、期望值比率（expectancy ratio）、胜率
- 对低交易频率施加惩罚
- 各指标权重隐含在归一化和组合公式中

Freqtrade 的自定义损失函数示例中的权重分配：
- 交易时长权重：0.4
- 交易损失规避权重：0.25
- 总利润权重：1.0

#### 2.2.2 推荐的权重分配方案

基于研究和行业实践，推荐的权重分配方案如下：

| 交易质量 | 20% | Profit Factor(8%) + 期望值(7%) + 胜率(5%) |
| 稳定性 | 15% | 净值曲线 R-squared(6%) + 月度一致性(5%) + 交易频率稳定性(4%) |
| 鲁棒性 | 10% | 参数敏感度(5%) + Walk-Forward 比率(5%) |

**方案 B：激进型（侧重收益）**

| 维度类别 | 权重 | 包含指标 |

**方案 C：保守型（侧重风险控制）**

| 维度类别 | 权重 | 包含指标 |
|----------|------|----------|
| 风险调整收益 | 25% | Sortino 比率(15%) + Calmar 比率(10%) |

#### 2.2.3 动态权重调整机制

除了固定权重，建议引入动态权重调整：

1. **基于进化阶段的动态权重**：
   - 进化早期：侧重收益和交易质量（鼓励探索有潜力的策略）
   - 进化中期：逐步增加稳定性和风险控制权重
   - 进化后期：增加鲁棒性权重（筛选真正可靠的策略）

2. **基于市场状态的动态权重**：
   - 趋势行情：降低波动率权重，增加收益权重
   - 震荡行情：增加稳定性权重，降低收益期望
   - 高波动期：增加风险控制权重

### 2.3 交易次数惩罚机制分析

#### 2.3.1 当前机制的问题

当前的交易次数惩罚机制可能是以下形式之一：
- 交易次数 < N 时，总分乘以惩罚系数
- 交易次数 < N 时，施加固定惩罚

存在的问题：
- 统计显著性不足：10 笔交易的 60% 胜率与 100 笔交易的 60% 胜率，统计意义完全不同
- 惩罚函数过于突兀（阶跃函数），缺乏平滑过渡
- 没有考虑回测期间的长度

#### 2.3.2 Freqtrade 的处理方式

Freqtrade 的 MultiMetricHyperOptLoss 对低交易频率的惩罚方式：
- 交易次数低于某个阈值时，惩罚项增大
- 通过指数函数实现平滑过渡
- 公式形式类似：trade_loss = 1 - 0.25 * exp(-(trade_count - TARGET)^2 / 10^5.8)

#### 2.3.3 改进建议

**基于统计显著性的惩罚**：

推荐使用威尔逊置信区间下界作为替代：

- 任意统计指标（如胜率、Profit Factor）都受样本量影响
- 交易次数 N 时胜率 p 的 95% 置信区间：p - 1.96 * sqrt(p*(1-p)/N)
- 使用置信区间下界代替原始值进行评分，自然实现"交易次数少则评分打折"
- 无需显式的惩罚机制，统计理论自带调节

**渐进式惩罚函数**：

使用 Sigmoid 或指数函数实现平滑过渡：
- penalty = 1 / (1 + exp(-k * (trade_count - threshold)))
- k 控制过渡的平滑度，threshold 控制惩罚开始生效的交易次数
- 推荐参数：threshold = 30, k = 0.2

### 2.4 鲁棒性评分研究

#### 2.4.1 为什么需要鲁棒性评分

进化优化容易产生过拟合策略：
- 策略在回测数据上表现优异但在实盘中表现差
- 参数微小的变化导致策略表现急剧恶化
- 策略只在回测期间的特定时段表现好

鲁棒性评分旨在量化这些风险。

#### 2.4.2 鲁棒性评分维度

| 维度 | 实现方法 | 计算成本 | 推荐程度 |
|------|----------|----------|----------|
| **参数敏感度** | 在最优参数周围 +-10%、+-20% 微调，计算评分变化率 | 中 | 强烈推荐 |
| **Walk-Forward 验证** | 将数据分为多段（如 70% 训练 / 30% 测试），计算 OOS/IS 比率 | 高 | 强烈推荐 |
| **滚动窗口稳定性** | 用滚动窗口（如 6 个月）计算各窗口表现，取最差窗口评分 | 中 | 推荐 |
| **蒙特卡洛验证** | 随机打乱交易顺序 1000 次，计算原始表现的百分位排名 | 中 | 推荐 |
| **Bootstrap 验证** | 从交易记录中有放回抽样，计算统计指标的置信区间 | 中 | 推荐 |
| **噪声注入测试** | 在信号中加入随机噪声，观察策略表现的衰减程度 | 低 | 可选 |

#### 2.4.3 Freqtrade / FreqAI 的 Walk-Forward 实践

FreqAI（Freqtrade 的机器学习模块）使用滑动窗口训练方法：
- 将数据分为多个训练/测试窗口
- 每个窗口独立训练和验证
- 汇总所有窗口的样本外表现

这种方法可有效评估策略的时间稳定性和过拟合程度。

#### 2.4.4 推荐的鲁棒性评分实现

**参数敏感度评分（低计算成本）**：

1. 对策略的最优参数集，在 +-5%、+-10%、+-20% 三个扰动级别各生成 5 组参数变体
2. 在相同回测数据上评估所有变体
3. 计算原始评分与变体评分的比率：
   - 如果变体评分 / 原始评分 > 0.8，说明参数鲁棒
   - 如果变体评分 / 原始评分 < 0.5，说明参数敏感（可能过拟合）
4. 取所有变体比率的均值作为参数鲁棒性得分

**Walk-Forward 评分（高计算成本但最可靠）**：

1. 将回测数据分为 N 段（推荐 N=5）
2. 每段用前一段的数据优化参数，在本段验证
3. 计算 OOS 平均表现 / IS 平均表现
4. 比率 > 0.5 为可接受，> 0.7 为良好，< 0.3 为严重过拟合

**综合鲁棒性评分**：

robustness_score = 0.5 * parameter_sensitivity + 0.5 * walk_forward_ratio

## 三、改进建议

### 3.1 评分维度重构

#### 3.1.1 移除冗余指标

- 移除 annual_return：其信息已被 Sharpe 比率和 Calmar 比率间接覆盖
- 保留 sharpe_ratio 但降低其权重，因为 Sortino 比率更优

#### 3.1.2 新增核心指标（优先级排序）

| 优先级 | 指标 | 理由 |
|--------|------|------|
| P0 | **Sortino 比率** | 仅惩罚下行风险，比夏普比率更准确；Freqtrade 已内置 SortinoHyperOptLoss |
| P0 | **Profit Factor** | 直接衡量策略盈利能力，是交易系统最核心的指标之一 |
| P0 | **净值曲线 R-squared** | 衡量收益曲线的线性程度，是最直观的稳定性指标 |
| P1 | **最大连续亏损** | 实盘心理承受的关键指标 |
| P1 | **参数敏感度** | 检测过拟合的最基础手段 |
| P1 | **Walk-Forward 比率** | 最可靠的过拟合检测方法 |
| P2 | **VaR/CVaR** | 尾部风险度量，专业机构标准指标 |
| P2 | **月度收益一致性** | 收益时间分布的均匀性 |
| P2 | **交易频率稳定性** | 防止策略仅在特定行情活跃 |
| P3 | **超额收益** | 需要定义合理的基准 |
| P3 | **收益率偏度/峰度** | 分布特性的精细描述 |

#### 3.1.3 重构后的评分体系

```
总分 = 收益能力(30) + 风险控制(25) + 交易质量(20) + 稳定性(15) + 鲁棒性(10)
```

每个维度内部采用加权归一化：

| 维度 | 权重 | 子指标及内部分配 |
|------|------|------------------|
| 收益能力 | 30 | Sharpe 比率(12) + Sortino 比率(10) + Calmar 比率(8) |
| 风险控制 | 25 | 最大回撤(10) + 波动率(8) + 最大连续亏损(7) |
| 交易质量 | 20 | Profit Factor(8) + 期望值(7) + 胜率(5) |
| 稳定性 | 15 | 净值曲线 R-squared(6) + 月度一致性(5) + 交易频率稳定性(4) |
| 鲁棒性 | 10 | 参数敏感度(5) + Walk-Forward 比率(5) |

### 3.2 指标归一化方法

不同指标的量纲和范围不同，需要归一化到 0-100 分：

| 归一化方法 | 适用场景 | 公式 |
|------------|----------|------|
| **排名百分位** | 通用，不受极端值影响 | score = rank_in_population / population_size * 100 |
| **Sigmoid 映射** | 有明确目标范围的指标 | score = 100 / (1 + exp(-k * (value - target))) |
| **分段线性** | 有明确阈值的指标 | score = piecewise_linear(value, thresholds) |
| **Min-Max 归一化** | 有已知上下界的指标 | score = (value - min) / (max - min) * 100 |

推荐方案：
- 对于种群内评分（进化过程中）：使用**排名百分位**，避免极端值影响
- 对于绝对评分（最终策略评估）：使用 **Sigmoid 映射**，将各指标映射到有意义的 0-100 分

各指标的 Sigmoid 映射参考参数：

| 指标 | 目标值(target) | 斜率(k) | 说明 |
|------|----------------|---------|------|

### 3.3 交易次数处理改进

#### 3.3.1 统计显著性置信因子

替代显式的交易次数惩罚，引入基于统计理论的置信因子：

```
confidence_factor = min(1.0, trade_count / min_required_trades)
```

其中 min_required_trades 的推荐值：
- 日内策略：50
- 波段策略：30
- 趋势策略：20

#### 3.3.2 指标置信区间修正

对每个统计指标，用置信区间下界代替原始值：

```
adjusted_win_rate = win_rate - z * sqrt(win_rate * (1 - win_rate) / trade_count)
```

其中 z = 1.96（95% 置信度）。

交易次数越多，置信区间越窄，adjusted 值越接近原始值。交易次数少时，adjusted 值会显著低于原始值，自然实现惩罚效果。

### 3.5 与进化策略的联动

评分体系与进化策略的算子选择有密切关系：

| 评分用途 | 在进化策略中的应用 |
|----------|-------------------|
| 适应度函数 | 评分总分作为进化策略的适应度值，驱动选择和淘汰 |
| 多目标拆分 | 五个维度的得分可作为 NSGA-II 的独立目标，避免加权组合的信息损失 |
| 终止条件 | 最优个体的鲁棒性得分 > 阈值时终止进化 |
| 精英选择 | 按"收益能力 * 鲁棒性"排序选择精英，避免选择过拟合的高分策略 |
| 自适应权重 | 根据种群在各维度得分的分布，动态调整权重以增加区分度 |
