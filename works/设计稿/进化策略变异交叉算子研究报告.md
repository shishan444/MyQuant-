# 进化策略中变异/交叉/选择算子研究报告

## 一、当前做法的问题分析

### 1.1 当前系统已有算子

当前系统实现了 7 种变异操作：

| 编号 | 算子名称 | 描述 |
|------|----------|------|
| 1 | 参数微调 | 对策略参数进行小幅随机调整 |
| 2 | 指标替换 | 替换策略中的技术指标 |
| 3 | 逻辑翻转 | 翻转买卖条件逻辑 |
| 4 | 风控参数调整 | 修改止损/止盈等风险参数 |
| 5 | 添加条件信号 | 在策略中新增过滤条件 |
| 6 | 删除条件信号 | 移除策略中的过滤条件 |
| 7 | 跨层逻辑翻转 | 在不同信号层之间翻转逻辑关系 |

### 1.2 存在的问题

1. **缺乏交叉算子**：当前系统仅有变异操作，没有实现任何交叉算子。交叉是遗传算法中产生新解的核心机制，缺失交叉会导致种群多样性不足、收敛速度慢。

2. **缺乏自适应机制**：所有变异操作使用固定概率，无法根据进化阶段或个体适应度动态调整。早期需要大步探索，后期需要精细搜索。

3. **选择机制未知**：不确定当前是否使用了高级选择策略（如锦标赛选择、NSGA-II 等），基础的选择策略可能导致过早收敛。

4. **缺乏多目标选择**：量化策略优化天然是多目标问题（收益、风险、稳定性），但未明确是否采用了多目标进化算法（MOEA）。

5. **变异粒度单一**：当前变异操作要么是微调参数，要么是结构变更（添加/删除），缺乏中间粒度的结构重组能力。

6. **缺乏约束处理机制**：策略生成后可能产生无效个体（如参数越界、逻辑矛盾等），当前未见明确的约束修复机制。

## 二、研究发现 -- 进化算子完整分类体系

### 2.1 交叉算子（Crossover Operators）

#### 2.1.1 实数编码交叉（适用于参数空间优化）

| 算子名称 | 原理 | 量化策略适用性 | 实现复杂度 | 推荐优先级 |
|----------|------|----------------|------------|------------|
| **算术交叉** (Arithmetic Crossover) | 子代 = alpha * parent1 + (1-alpha) * parent2，alpha 为混合系数 | 高 -- 适合连续参数（RSI阈值、止损百分比等）的平滑融合 | 低 | P0 |
| **BLX-alpha 交叉** (Blend Crossover) | 在 [min-alpha*d, max+alpha*d] 区间均匀采样，d 为父代差值 | 高 -- 扩展搜索范围，避免过早收敛于父代之间 | 低 | P0 |
| **SBX 交叉** (Simulated Binary Crossover) | 模拟二进制交叉的实数版本，通过分布指数控制后代与父代的相似度 | 高 -- DEAP 框架内置（cxSimulatedBinaryBounded），可控制探索/利用平衡 | 低 | P0 |
| **DE 两点交叉** (cxESTwoPoint) | 进化策略专用的两点交叉，交换中间段基因 | 中 -- 适合参数向量的局部交换 | 低 | P1 |
| **DE 混合交叉** (cxESBlend) | 进化策略混合交叉，混合策略参数（步长）和个体参数 | 中 -- CMA-ES 中常用，可自适应调整步长 | 中 | P1 |
| **均匀交叉** (Uniform Crossover) | 每个基因位以独立概率 p 选择来自父代1或父代2 | 高 -- 保持多样性，适合多层策略的层间交换 | 低 | P0 |
| **单点/两点交叉** (1-point/2-point Crossover) | 在随机位点切断，交换片段 | 中 -- 经典算子，适合策略结构的局部交换 | 低 | P1 |
| **差分进化交叉** (DE Crossover) | trial = mutant if rand < CR else target，CR 为交叉率 | 高 -- DE 算法核心，适合连续优化，收敛性能优异 | 中 | P0 |

#### 2.1.2 树/图结构交叉（适用于策略逻辑进化）

| 算子名称 | 原理 | 量化策略适用性 | 实现复杂度 | 推荐优先级 |
|----------|------|----------------|------------|------------|
| **子树交换交叉** (Subtree Crossover) | 在两个树形策略中随机选择节点，交换以该节点为根的子树 | 高 -- GP 核心算子，适合交易规则树的进化重组 | 中 | P0 |
| **语义交叉** (Semantic Crossover) | offspring = parent1 + logistic * (random_tree1 - random_tree2)，保证语义连续性 | 高 -- 避免破坏已有有效语义，收敛更稳定 | 高 | P2 |
| **单点叶子偏向交叉** (cxOnePointLeafBiased) | 以概率 termpb 选择叶子节点或内部节点进行交换 | 中 -- 可控制交换粒度，倾向于交换终端符号或函数节点 | 中 | P2 |
| **部分匹配交叉** (PMX) | 交换片段后修复冲突，保持排列有效性 | 低 -- 主要用于排列编码（TSP问题），策略优化中不常用 | 中 | P3 |
| **有序交叉** (Ordered Crossover) | 保持基因排列顺序的交叉 | 低 -- 排列编码专用，策略优化中不常用 | 中 | P3 |
| **均匀部分匹配交叉** (Uniform PMX) | PMX 的均匀版本 | 低 | 中 | P3 |
| **混乱交叉** (Messy One-Point) | 允许基因缺失或重复的交叉 | 低 -- 适合变长编码 | 中 | P3 |

#### 2.1.3 高级交叉策略

| 策略名称 | 原理 | 量化策略适用性 | 实现复杂度 | 推荐优先级 |
|----------|------|----------------|------------|------------|
| **多亲交叉** (Multi-parent Crossover) | 使用 3 个或更多父代产生子代，如对角线交叉、Gaussian Mixture 交叉 | 中 -- 增加基因池多样性，降低对单一优秀个体的依赖 | 中 | P1 |
| **自适应交叉率** (Adaptive Crossover Rate) | 根据种群多样性指标或进化代数动态调整交叉概率 | 高 -- 自动平衡探索与利用，减少调参负担 | 中 | P0 |
| **物种形成交叉** (Speciation Crossover) | 仅在相似个体间交叉（基于基因距离），保护创新 | 中 -- 适合策略种群多样性维护 | 高 | P2 |
| **分层交叉** (Hierarchical Crossover) | 在策略不同层次（信号层、过滤层、风控层）分别执行交叉 | 高 -- 完美匹配量化策略的多层架构 | 高 | P1 |

### 2.2 变异算子（Mutation Operators）

#### 2.2.1 实数编码变异（参数空间）

| 算子名称 | 原理 | 量化策略适用性 | 实现复杂度 | 推荐优先级 |
|----------|------|----------------|------------|------------|
| **高斯变异** (Gaussian Mutation) | 在基因值上叠加 N(0, sigma) 噪声 | 高 -- 最经典的连续变异，适合所有数值参数 | 低 | P0 |
| **自适应高斯变异** (Adaptive Gaussian) | sigma 随进化代数或个体适应度动态调整（1/5 规则或 CMA） | 高 -- CMA-ES 核心机制，自动调整步长 | 中 | P0 |
| **多项式变异** (Polynomial Mutation) | 基于多项式概率分布的扰动，有界版本可约束参数范围 | 高 -- DEAP 内置（mutPolynomialBounded），保证参数不越界 | 低 | P0 |
| **均匀整数变异** (Uniform Int Mutation) | 在指定范围内均匀随机取整数值 | 高 -- 适合离散参数（如 SMA 周期 5-200） | 低 | P0 |
| **柯西变异** (Cauchy Mutation) | 使用柯西分布代替高斯分布，产生更频繁的大步跳跃 | 中 -- 增强逃离局部最优的能力 | 低 | P1 |
| **对立变异** (Opposition-based Mutation) | 生成当前解的对立点（如 x -> lb+ub-x） | 中 -- 加速初始种群收敛 | 低 | P1 |
| **DE 变异** (DE Mutation) | v = x_r1 + F * (x_r2 - x_r3)，差分向量的线性组合 | 高 -- DE 算法核心，收敛速度快 | 中 | P0 |
| **自适应对数正态变异** (ES Log-normal) | 同时变异策略参数（步长）和目标参数，步长使用对数正态分布 | 高 -- 进化策略标准方法（mutESLogNormal），实现自适应 | 中 | P1 |

#### 2.2.2 树/图结构变异（策略逻辑）

| 算子名称 | 原理 | 量化策略适用性 | 实现复杂度 | 推荐优先级 |
|----------|------|----------------|------------|------------|
| **子树替换变异** (Subtree Replacement) | 随机选择节点，用随机生成的子树替换 | 高 -- GP 标准变异，引入新逻辑结构 | 中 | P0 |
| **节点替换变异** (Node Replacement) | 仅替换单个节点（如将 + 替换为 -），保持树结构不变 | 高 -- 小粒度变异，适合逻辑微调 | 低 | P1 |
| **收缩变异** (Shrink Mutation) | 随机选择内部节点，用其随机子节点替换（降低复杂度） | 高 -- 控制策略复杂度，防止 bloat | 低 | P0 |
| **插入变异** (Insert Mutation) | 在随机位置插入一个新的内部节点 | 中 -- 增加策略复杂度 | 低 | P2 |

| **HO 变异** (Higher Order Mutation) | 同时修改多个位置（二阶/三阶变异） | 中 -- 适合突破局部最优 | 中 | P2 |
| **指标变异** (Indicator Mutation) | 专用于量化策略：替换技术指标类型或参数 | 高 -- 当前系统已有（指标替换），但可扩展 | 低 | P0 |
| **条件增删变异** (Condition Add/Delete) | 专用于量化策略：添加或删除过滤条件 | 高 -- 当前系统已有，但可增加条件合并/拆分变体 | 低 | P0 |

## 三、改进建议

### 3.1 优先级 P0 -- 立即实施

#### 3.1.1 引入交叉算子

当前系统缺失交叉操作，这是最紧迫的改进。推荐首先实现以下交叉算子：

1. **算术交叉 / SBX 交叉**：用于策略参数的融合。当两个策略结构相似但参数不同时，通过算术交叉产生介于两者之间的参数组合。
2. **子树交换交叉**：用于策略逻辑的重组。在策略规则树上选择交叉点，交换子树，实现不同策略模块的组合。
3. **均匀交叉**：用于多层策略的层间交换，以一定概率交换不同层的配置。

#### 3.1.2 引入差分进化（DE）变异

DE 是连续参数优化最有效的方法之一。推荐实现以下 DE 变体：

- **DE/rand/1**: v = x_r1 + F * (x_r2 - x_r3) -- 经典版本，探索性强
- **DE/best/1**: v = x_best + F * (x_r1 - x_r2) -- 利用性强，收敛快
- **DE/current-to-best/1**: v = x_i + F * (x_best - x_i) + F * (x_r1 - x_r2) -- 平衡探索与利用

#### 3.1.3 实现锦标赛选择 + 精英保留

- 锦标赛选择（k=3~7）是通用性最强的选择方法，建议作为默认选择算子
- 精英保留比例建议为种群大小的 5%~10%
- 两者组合可兼顾收敛速度和种群多样性

#### 3.1.4 引入约束处理机制

使用 DEAP 内置的 DeltaPenalty 装饰器对变异/交叉后的个体进行约束检查，对以下约束施加惩罚：
- 参数越界（如 RSI 周期 < 2）
- 策略逻辑矛盾（如买入条件永远不触发）
- 交易次数过少（如回测期间 < 10 笔）

#### 3.1.5 多项式有界变异

使用 DEAP 的 mutPolynomialBounded 替代简单的参数微调，该算子：
- 自动保证参数在边界内
- 通过分布指数 eta 控制扰动大小
- eta 小则扰动大（探索），eta 大则扰动小（利用）

### 3.2 优先级 P1 -- 短期实施

#### 3.2.1 实现自适应变异率

推荐使用 1/5 成功规则：
- 统计最近 N 次变异中产生更优个体的比例
- 如果成功率 > 1/5，增大变异步长（更激进探索）
- 如果成功率 < 1/5，减小变异步长（更精细搜索）
- 如果成功率 = 1/5，保持不变

#### 3.2.2 引入多目标选择（NSGA-II）

量化策略优化天然是多目标问题。建议使用 NSGA-II 同时优化：
- 目标1：最大化年化收益
- 目标2：最大化夏普比率
- 目标3：最小化最大回撤

NSGA-II 将输出一组 Pareto 最优策略，用户可根据偏好选择。

#### 3.2.3 引入岛屿模型

使用 DEAP 的 migRing 实现环形迁移的岛屿模型：
- 推荐岛屿数量：4~8 个
- 迁移间隔：每 10~20 代迁移一次
- 迁移个体数：每个岛屿 1~3 个
- 不同岛屿可使用不同的变异参数，增加种群多样性

#### 3.2.4 模因算法（混合局部搜索）

在 EA 每一代的最优个体上执行局部搜索：
- 参数空间的局部搜索：爬山法或 Nelder-Mead
- 逻辑空间的局部搜索：贪心条件增删
- 局部搜索迭代次数：5~10 次即可

#### 3.2.5 分层交叉

针对量化策略的多层架构（信号层、过滤层、风控层），设计分层交叉策略：
- 信号层交叉：交换主要买卖信号逻辑
- 过滤层交叉：交换过滤条件组合
- 风控层交叉：交换止损止盈参数
- 可独立选择交叉的层级组合

### 3.3 优先级 P2 -- 中期实施

#### 3.3.1 CMA-ES 集成

在参数优化阶段使用 CMA-ES 替代标准变异：
- 适合已确定策略结构后、仅优化参数的场景
- CMA-ES 会自动学习参数间的相关性
- DEAP 中可通过 cxESBlend + mutESLogNormal 实现基础 ES

#### 3.3.2 语义交叉/变异

对 GP 树形策略实现语义操作：
- 保证变异前后的语义连续性
- 减少无效变异（语义交叉产生的后代保证包含父代信息）
- 实现复杂度较高，但收敛稳定性显著提升

#### 3.3.3 自适应算子选择

维护算子性能统计表，动态选择表现最好的算子：
- Credit Assignment: 基于最近 N 次使用某算子产生的适应度改善
- Operator Selection: 基于 Credit 的概率选择（如 UCB、Probability Matching）
- 可自动发现最优的算子组合，减少人工调参

#### 3.3.4 协同进化

- 策略种群 vs 市场环境种群：市场环境包含不同行情类型（趋势、震荡、极端波动），策略需要在不同环境下都表现良好
- 买方策略 vs 卖方策略：分别进化买入和卖出逻辑

### 3.4 实施路线图

```
Phase 1 (P0, 1-2周):
  + 引入 SBX/算术交叉 (参数空间)
  + 引入子树交换交叉 (逻辑空间)
  + 引入均匀交叉 (层间)
  + 引入 DE 变异 (DE/rand/1, DE/best/1)
  + 实现锦标赛选择 + 精英保留
  + 引入 DeltaPenalty 约束处理
  + 引入多项式有界变异

Phase 2 (P1, 2-4周):
  + 实现自适应变异率 (1/5 规则)
  + 实现 NSGA-II 多目标选择
  + 实现岛屿模型 + 环形迁移
  + 实现模因算法 (EA + 局部搜索)
  + 实现分层交叉

Phase 3 (P2, 4-8周):
  + 集成 CMA-ES
  + 实现语义交叉/变异
  + 实现自适应算子选择
  + 探索协同进化机制
```

### 3.5 算子组合推荐方案

针对量化策略优化的推荐算子组合：

| 进化阶段 | 选择算子 | 交叉算子 | 变异算子 | 说明 |
|----------|----------|----------|----------|------|
| **早期探索** | 锦标赛 (k=2) | SBX (eta=2), 子树交换 | DE/rand/1, 高斯 (sigma=0.3), 柯西 | 大步探索，低选择压力 |
| **中期平衡** | 锦标赛 (k=5) | 算术 (alpha=0.5), 均匀 | DE/best/1, 多项式 (eta=20) | 平衡探索与利用 |
| **后期精炼** | 锦标赛 (k=7) | 算术 (alpha=0.3) | 自适应高斯, 局部搜索 | 精细搜索，高选择压力 |
| **多目标** | NSGA-II | 任意交叉 | 任意变异 | 同时优化收益/风险/稳定性 |
| **并行** | 岛屿内锦标赛 + 环形迁移 | 岛屿内交叉 | 岛屿内变异 | 多种群并行进化 |
