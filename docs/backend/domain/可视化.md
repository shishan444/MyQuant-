# 可视化 (visualization)

## 职责与边界
**负责**：
- 冠军策略报告图表构建协调（K 线图 + 权益曲线 + 快速预览）
- 进化监控面板图表（代际趋势图）
- K 线图生成：蜡烛图 + 买卖标记 + 指标叠加 + RSI 子图
- 权益曲线图：策略 vs 买入持有基准对比
- 快速预览图：vectorbt Portfolio.plot() 的封装

**不负责**：
- 数据计算与策略执行（委托给 backtest/engine 和 strategy/executor）
- 前端渲染与交互（由 web/ 承担）
- 图表数据的前后端传输（由 api/ 承担）

**边界**：接收 DataFrame、信号序列、回测结果等结构化数据，返回 Plotly Figure 对象。不直接读写数据库或文件系统。

## 设计意图
可视化模块采用"协调器+专用构建器"模式。chart_builder 作为唯一对外入口，编排"DNA -> 信号 -> 回测 -> 多图表"的完整管线。每个子模块（kline_chart、equity_curve、generation_chart、quick_preview）只负责单一图表类型的构建，保持职责内聚。

图表选择 Plotly 而非 Matplotlib，原因是 Plotly 原生支持交互式图表（缩放、悬停、切换），且可以直接序列化为 JSON 传递给前端渲染。

## 模块依赖
| 依赖模块 | 依赖原因 |
|----------|----------|
| backtest/engine (BacktestEngine, BacktestResult) | 运行回测获取权益曲线和交易记录 |
| strategy/dna (StrategyDNA) | 读取 DNA 的 signal_genes 确定叠加指标 |
| strategy/executor (dna_to_signals) | 将 DNA 转换为入场/出场信号序列 |
| plotly (graph_objects, subplots) | 图表构建库 |

## 业务规则与不变量
- K 线图布局：上方 70% 价格区域（蜡烛图 + 指标线 + 标记），下方 30% RSI（30/70 水平线）
- 权益曲线归一化：策略和基准均以起始点为 100% 基准
- 指标叠加选择：仅叠加 DNA signal_genes 中实际使用的指标，最多 5 条线避免拥挤
- generation 图表：best_score 绿线、avg_score 橙线、target_score 红色虚线
- quick_preview 无交易时返回占位图（"No trades in this strategy"）
- 所有图表统一使用 plotly_dark 主题
