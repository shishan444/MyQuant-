# 特征工程

## 职责与边界

**负责**：
- 管理指标注册表（30+ 个技术指标，8 个类别）
- 批量计算技术指标并附加到行情 DataFrame
- 定义指标使用画像（推荐参数 / 推荐角色 / 推荐条件）
- 信号构建（DNA 指标需求提取 + 信号生成）
- K 线形态检测（8 个经典形态）
- 背离检测（多头/空头背离）
- ML 指标计算（分形熵 / 多因子振荡器）

**不负责**：
- 策略信号评估逻辑（由 strategy/executor 负责）
- 进化变异操作（由 evolution/operators 负责）

**边界**：本模块是"指标"领域的权威来源。注册表定义了指标的全部元信息（参数范围 / 输出字段 / 支持的条件类型），其他模块通过注册表获取指标知识。指标画像（indicator_profile）引导进化方向，但不直接执行变异。

## 业务规则与不变量

1. **注册表覆盖**：INDICATOR_REGISTRY 包含 30+ 指标，分 8 个类别 -- trend(6) / momentum(9) / volatility(4) / volume(8) / trend_strength(2) / pattern(10) / derivatives(5) / ml(2)
2. **列名单一真相源**：resolve_indicator_column 是列名解析的唯一入口，所有消费者（executor / signal_builder / indicators）必须通过此函数解析列名
3. **画像遵循概率**：每个指标的 follow_probability 默认 0.70，即 70% 遵循推荐用法，30% 自由探索
4. **lazy 指标**：VolumeProfile / FractalEntropy / MultifactorOsc 标记为 compute_mode="lazy"，默认跳过以节省计算量
5. **guard_only 指标**：ATR / ADX / PSAR / VWAP 标记为 guard_only，不能作为 trigger 信号使用
6. **参数 clamp**：ParamDef.clamp() 确保参数值在合法范围内并对齐步长边界
7. **高级条件推荐**：趋势类指标（EMA/SMA/WMA/DEMA/TEMA/VWMA/Aroon）的画像包含 cross_above_series / cross_below_series 条件，BB 包含 lookback_any / lookback_all 条件。Profile 引导路径（70% 概率）可以生成双指标交叉和回看窗口条件

## 设计意图

指标注册表（registry.py）采用声明式设计：每个指标的全部元信息集中定义，包括参数范围、输出字段、支持的条件类型。这种设计消除了代码中的硬编码 if/elif 链，使得新增指标只需在注册表中添加一条记录。

指标画像（indicator_profile.py）是对进化效率的关键优化。未经引导的随机进化会产生大量无效组合；画像基于量化交易实践和开源框架（freqtrade / backtrader / vectorbt / Investopedia）提炼出每个指标的推荐用法，以 70% 概率引导进化遵循有效路径，同时保留 30% 自由探索能力。画像的推荐条件覆盖 16 种条件类型中的高级条件（cross_above_series、lookback_any 等），确保引导路径不仅限于基础 lt/gt 条件。

ML 指标（分形熵 / 多因子振荡器）采用 lazy 计算模式，仅在明确需要时才计算，避免对不需要这些指标的策略产生计算开销。
