# 持久化层 (persistence)

## 职责与边界
**负责**：
- SQLite 数据库初始化与连接管理（WAL 模式）
- 进化任务的 CRUD 操作（创建、更新、查询、列表）
- 种群快照存储：完整种群 DNA 序列化 + 检查点恢复
- 进化历史记录：轻量级评分记录（供 UI 图表使用）
- 断电恢复：从最新检查点反序列化种群继续进化

**不负责**：
- 进化算法逻辑（由 evolution/engine 承担）
- DNA 编码与解码的语义（由 strategy/dna 承担）
- 模拟交易任务持久化（由 api/db_ext 承担）

**边界**：接收 Path 类型的数据库路径和结构化参数，返回 dict 或序列化对象。不管理数据库连接池（每次操作开闭连接），适合单进程 SQLite 场景。

## 数据模型

### evolution_task 表
| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | TEXT PK | 任务唯一标识 |
| status | TEXT | 状态：running / completed / stopped |
| target_score | REAL | 目标分数 |
| score_template | TEXT | 评分模板名称 |
| symbol | TEXT | 交易对 |
| timeframe | TEXT | K 线周期 |
| initial_dna | TEXT (JSON) | 初始策略 DNA |
| champion_dna | TEXT (JSON) | 冠军策略 DNA（可为空） |
| strategy_threshold | REAL | 策略阈值（默认 80.0） |
| created_at / updated_at | TEXT (ISO) | 时间戳 |
| stop_reason | TEXT | 停止原因 |

### generation_snapshot 表
| 字段 | 类型 | 说明 |
|------|------|------|
| task_id + generation | PK | 联合主键 |
| best_score / avg_score | REAL | 本代最优/平均分数 |
| best_dna | TEXT (JSON) | 最优个体 DNA |
| population_json | TEXT (JSON) | 完整种群 DNA 数组 |
| mutation_log | TEXT | 变异日志 |
| wf_months | TEXT | Walk-forward 月份配置 |
| created_at | TEXT (ISO) | 创建时间 |

### evolution_history 表
| 字段 | 类型 | 说明 |
|------|------|------|
| task_id + generation | PK | 联合主键 |
| best_score / avg_score | REAL | 轻量级评分记录 |
| top3_summary | TEXT (JSON) | Top3 摘要 |
| created_at | TEXT (ISO) | 创建时间 |

## 业务规则与不变量
- SQLite WAL 模式 + NORMAL 同步 + 5000ms 忙等待，兼顾性能与可靠性
- population_json 字段存储完整种群所有个体的 DNA 字典数组
- INSERT OR REPLACE 语义保证同一代只保留一份快照
- resume_evolution 要求 task status == "running" 才允许恢复
- 数据库迁移使用 ALTER TABLE + try/except 模式（列已存在则跳过）
