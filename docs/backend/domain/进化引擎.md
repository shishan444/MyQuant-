# 进化引擎

## 职责与边界

**负责**：
- 进化主循环（初始化 -> 代际循环 -> 早停判定）
- 变异操作（参数 / 指标 / 逻辑 / 风险 / 信号增删 / MTF 层操作，共 13 个变异函数）
- 交叉操作（双亲基因混合）
- 种群初始化（7 种策略模板 + 随机生成 + 画像引导）
- 多样性维护（基因型 + 表型距离 + 适应度共享 + 新鲜血液注入）
- 冠军追踪（线程安全的名人堂模式）
- 血统追踪（变异历史记录）

**不负责**：
- 回测执行（由 backtest 模块负责）
- 评分计算（由 scoring 模块负责）
- API / 任务调度（由 api/runner 负责）

**边界**：本模块接受 evaluate_fn（评分函数由外部注入），输出进化结果（champion + history + stop_reason）。模块不持有任何 I/O 资源，不直接操作数据库。

## 状态机

```
[初始化] --> [运行中: 代际循环]
                |
                +-- 目标达成 --> [完成: target_reached]
                +-- 停滞 --> [完成: stagnation]
                +-- 衰退 --> [完成: decline]
                +-- 最大代数 --> [完成: max_generations]
```

### 早停规则（EarlyStopChecker）

| 规则 | 条件 | 说明 |
|---|---|---|
| target_reached | best_score >= target 且 gen >= min_generations | 达到目标分数 |
| stagnation | 连续 patience 代无改善（< min_improvement） | 搜索停滞 |
| decline | 连续 decline_limit 代最佳分数下降 | 种群退化 |
| max_generations | gen >= max_generations | 达到上限 |

## 业务规则与不变量

1. **锦标赛选择**：tournsize=3 的锦标赛选择替代截断选择，保持选择压力的同时允许弱个体偶尔繁殖
2. **精英保留**：top elite_ratio（默认 15%，最少 2 个）直接进入下一代
3. **新鲜血液**：每代注入 3-5 个随机个体保持多样性
4. **多样性维护**：基因型多样性低于 30% 时，用随机个体替换重复个体
5. **自适应变异强度**：基于 1/5 成功法则（Rechenberg），停滞时加强探索，改善时加强开发
6. **停滞自适应变异权重**：停滞 > 8 代时大幅增加指标替换权重，> 4 代时平衡权重
7. **MTF 变异**：支持 add_layer / remove_layer / layer_timeframe / cross_logic / mtf_mode / confluence_threshold / proximity_mult 共 7 种 MTF 专属变异
8. **变异函数池选择**：base/layer 随机选择变异目标，MTF 策略有 50% 概率变异 MTF 层
9. **参数变异方法**：优先使用画像推荐参数 -> 注册表候选值 -> 多项式有界变异（eta=20）

## 设计意图

进化引擎的核心权衡是"探索 vs 开发"。多个机制协同平衡这一张力：

- **锦标赛选择**（tournsize=3）提供了中等选择压力，比截断选择更有利于多样性
- **自适应变异控制器**（1/5 成功法则）动态调整变异强度，停滞时加大探索，进展顺利时加强开发
- **种群初始化 40/40/20 比例**确保每代都有来自模板、画像引导、自由探索三个来源的新个体
- **多样性维护**作为最后防线，在多样性低于阈值时强制注入新鲜个体

变异操作全部基于序列化 -> 修改字典 -> 反序列化的模式，保证每次变异都产生全新的 StrategyDNA 实例，避免共享引用导致的意外修改。
