# 价格预测 (prediction)

## 职责与边界
**负责**：
- 基于 GARCH(1,1) 在线波动率模型，预测下一根 K 线的价格区间（high/low）
- 8 个市场因子计算：波动率体制、布林带挤压、相对成交量、多尺度价格张力、ADX
- 动态 K 值调整：因子加权的宽度乘数，自适应市场状态
- 预测公式离线进化：遗传算法优化 PredictionDNA 参数和因子权重
- 预测器状态持久化与恢复（GARCH 状态、命中追踪）

**不负责**：
- 交易信号生成（由 strategy/executor 承担）
- 订单生成与定价（由 trading/order_generator 承担）
- 历史数据获取与存储（由 data/ 承担）

**边界**：接收 DataFrame（含指标列）和 PredictionDNA，输出 PredictionResult（预测区间）。模块完全自包含，仅依赖 pandas 和标准库，不 import core/ 下任何其他子模块。通过 DataFrame 列名约定（atr_14, bb_upper_20_2 等）隐式依赖 features/ 的指标输出。

## 设计意图
预测系统采用 observe-predict 生命周期设计，与模拟交易 K 线循环对齐：(1) 每根 K 线先 observe 实际价格区间，更新 GARCH 状态和命中统计；(2) 然后 predict 下一根 K 线区间，结合 GARCH sigma 和因子加权的动态 K 值。这个设计使预测器可以在线运行，无需离线重训练。

GARCH(1,1) 递推公式：`sigma_sq = omega + alpha * epsilon^2 + beta * sigma_sq`，平稳性条件 alpha + beta < 1。离线进化器（PredictionEvolver）使用遗传算法优化 GARCH 参数、因子权重和窗口参数，在历史数据上寻找最优预测公式。

## 接口与契约

### 对外暴露的接口
| 接口 | 类型 | 签名 | 说明 |
|------|------|------|------|
| PriceRangePredictor | 类 | `__init__(dna: PredictionDNA)` | 核心预测器 |
| PriceRangePredictor.warmup | 方法 | `(df: DataFrame, n_bars: int = 100) -> None` | 历史数据预热 GARCH |
| PriceRangePredictor.predict | 方法 | `(df: DataFrame, idx: int) -> PredictionResult` | 预测下一 bar 区间 |
| PriceRangePredictor.observe | 方法 | `(actual_high: float, actual_low: float, predicted: PredictionResult) -> None` | 观测实际结果更新状态 |
| PriceRangePredictor.state_dict | 方法 | `() -> dict` | 导出运行时状态 |
| PriceRangePredictor.restore_state | 方法 | `(state: dict) -> None` | 恢复运行时状态 |
| PriceRangePredictor.hit_rate | property | `-> float` | 当前命中率 |
| PriceRangePredictor.needs_retrain | 方法 | `() -> bool` | 命中率 < 0.45 且样本 >= 50 |
| PredictionEvolver | 类 | `__init__(df: DataFrame, population_size: int = 60, max_generations: int = 50)` | 离线进化器 |
| PredictionEvolver.evolve | 方法 | `() -> PredictionDNA` | 运行遗传进化返回最优 DNA |
| compute_factors | 函数 | `(df: DataFrame, idx: int, dna: PredictionDNA) -> Dict[str, float]` | 计算 8 个市场因子 |

### 对外暴露的数据结构
| 数据结构 | 类型 | 用途 |
|-----------|------|------|
| PredictionDNA | dataclass | 预测公式基因：GARCH 参数(omega/alpha/beta)、宽度乘数(k_base/k_min)、8 因子权重、3 级窗口、进化元数据 |
| PredictionResult | dataclass | 预测输出：low/high（区间边界）、width（单侧半宽）、k_actual（实际 K 值） |
| GarchState | class(__slots__) | GARCH 在线状态：sigma_sq（当前方差）、epsilon（上次冲击） |
| FACTOR_POOL | dict | 8 个因子名到描述的映射 |
