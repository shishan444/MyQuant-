# 评分系统

## 职责与边界

**负责**：
- 从权益曲线和交易数据中提取原始绩效指标
- 将原始指标归一化到 0-100 分
- 定义评分模板（权重 + 阈值 + 硬约束）
- 计算策略综合评分

**不负责**：
- 回测执行（由 backtest 模块负责）
- 进化决策（由 evolution 模块负责）

**边界**：本模块接受回测结果（equity curve / trade returns），输出 0-100 综合评分。评分结果是进化选择的唯一依据，直接影响种群进化的方向。

## 业务规则与不变量

1. **零交易零分**：total_trades == 0 时直接返回 total_score = 0.0
2. **清算零分**：liquidated == True 时 total_score = 0.0（但保留维度分数供诊断）
3. **硬约束一票否决**：模板定义的 hard_constraints 中任一维度不满足，total_score 直接为 0
4. **交易次数惩罚**：通过 Sigmoid 函数计算交易因子，交易次数不足时按比例惩罚分数
5. **软约束惩罚**：max_drawdown_limit / min_annual_return_limit 不满足时按比例扣减分数（非零分）
6. **Sharpe 优先使用交易级数据**：有 trade_returns 时使用交易级 Sharpe，否则回退到 bar 级
7. **Alpha 计算**：Alpha = 策略年化收益 - 基准（无杠杆买入持有）年化收益

### 评分维度与归一化

核心维度使用分段线性归一化，对关键区间施加更高的梯度：

| 维度 | 分段断点设计 | 特点 |
|---|---|---|
| annual_return | [-1.0, 0] -> [0, 10], [0, 0.10] -> [10, 30], [0.50, 1.0] -> [80, 95] | 核心区间 [0%, 50%] 梯度最陡 |
| sharpe_ratio | [0.5, 1.0] -> [20, 50], [1.5, 2.0] -> [75, 90] | [0.5, 1.5] 为关键区间 |
| max_drawdown | 纯反向线性：0% dd = 100 分, 80% dd = 0 分 | 回撤越大分越低 |
| profit_factor | [1.0, 1.5] -> [30, 60], [2.0, 3.0] -> [80, 100] | 盈亏比 > 1 后陡升 |
| alpha | [-0.50, 0] -> [0, 40], [0, 0.50] -> [40, 80] | 超越基准为正分 |

### 模板定义

| 模板 | 权重侧重 | 阈值 | 硬约束 |
|---|---|---|---|
| explorer | annual_return 0.25 + sharpe 0.20 + alpha 0.15 | 50 | 无 |
| optimizer | sharpe 0.25 + monthly_consistency 0.20 + max_drawdown 0.15 | 65 | annual_return >= 10%, max_drawdown <= 60% |
| max_return | annual_return 0.40 + profit_factor 0.20 + alpha 0.15 | 40 | 无 |

## 设计意图

评分系统的核心设计选择是"分段线性归一化"而非简单的线性映射。不同指标在不同区间的区分价值不同 -- 例如 Sharpe 从 0.5 到 1.5 是区分策略好坏的关键区间，而 2.0 到 3.0 区间的差异相对次要。分段线性归一化允许对每个维度独立控制敏感度。

模板系统将评分策略从"固定算法"变为"可配置方案"。三个差异化模板对应不同的进化目标：explorer 宽松探索，optimizer 严格筛选，max_return 激进追求收益。硬约束机制确保特定底线（如最大回撤不超过 60%）被严格执行，而非仅仅影响分数。
