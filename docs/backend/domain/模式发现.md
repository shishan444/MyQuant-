# 模式发现 (discovery)

## 职责与边界
**负责**：
- 将技术指标编码为 ML 可用的归一化特征向量（最多 20 维）
- 基于未来价格走势生成分类标签（UP/DOWN/FLAT）与回归目标
- 通过决策树自动发现可解释的指标-方向映射规则
- 通过 KNN 匹配历史相似行情并预测未来价格区间
- 统计验证发现规则的置信度（Wilson 区间、Lift）

**不负责**：
- 实时信号生成（由 strategy/executor 承担）
- 数据获取与存储（由 data/ 承担）
- 回测执行（由 backtest/engine 承担）

**边界**：接收增强后的 DataFrame（OHLCV + 指标列），输出 DiscoveryResult / PredictionResult，不持有运行状态，适合批量离线分析。

## 设计意图
核心设计动机是"从历史数据中自动发现可解释的交易规律"。选择决策树（而非深度学习）是因为其结构天然可解释——每条从根到叶的路径就是一条可阅读的交易规则。KNN 提供补充视角：不建立显式模型，而是通过"历史上相似时刻后来怎么走"来预测。两者结合覆盖了"规则提取"和"相似案例匹配"两个互补的认知维度。

### 对外暴露的接口
| 接口 | 类型 | 签名 | 说明 |
|------|------|------|------|
| PatternDiscoveryEngine.discover | 方法 | `(df: DataFrame, target: str) -> DiscoveryResult` | 决策树规则发现主入口 |

| SimilarCaseEngine.predict | 方法 | `(features: ndarray, n_neighbors: int) -> PredictionResult` | 预测当前市场状态的未来走势 |

### 对外暴露的数据结构
| 数据结构 | 类型 | 用途 |
|-----------|------|------|
| DiscoveryResult | dataclass | 决策树发现结果：规则列表、准确率、CV 分数、特征重要性 |
| PredictionResult | dataclass | KNN 预测结果：方向、置信度、价格区间、相似案例 |
| SimilarCase | dataclass | 单个历史相似案例：时间、价格、距离、未来收益率 |
| RuleItem | dataclass | 单条可解释规则：条件列表、方向、置信度、样本数、Lift |

| numpy, pandas | 数值计算与数据操作 |

## 业务规则与不变量
- 特征向量维度上限 20 列，按指标类别优先级选取（动量 -> 趋势 -> 波动率 -> 成交量 -> 形态）
- 标签生成时前瞻窗口内最后 horizon 行标记为 NaN（无未来数据）
- 决策树 min_samples_leaf=50 防止过拟合，max_depth=5 限制规则复杂度
- 规则提取仅保留 Lift > 1.2 且方向为 UP/DOWN 的规则
- KNN 方向判定阈值：正收益占比 > 0.6 为 UP，< 0.4 为 DOWN，中间为 FLAT
