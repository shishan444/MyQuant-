# 假设验证流程

## 流程概述
用户提交 WHEN/THEN 交易假设（规则条件组），系统在历史数据上评估条件匹配、生成交易信号、统计胜率和分布，并返回验证结果。

## 触发入口
| 入口 | 类型 | 触发条件 |
|------|------|----------|
| POST /api/validate/rules | HTTP API | 用户提交规则条件验证 (新版) |
| POST /api/validate | HTTP API | 用户提交 DNA 验证 (旧版 WHEN/THEN) |
| POST /api/validate/scene | HTTP API | 场景验证 (由 scene 路由处理) |

## 模块序列
```mermaid
sequenceDiagram
    participant Frontend
    participant ValidateRoutes
    participant Storage
    participant Indicators
    participant RuleEngine
    participant ValidateEngine
    participant SceneEngine

    Frontend->>ValidateRoutes: POST /api/validate/rules
    ValidateRoutes->>RuleEngine: evaluate_rules(entry_conditions, exit_conditions)

    RuleEngine->>Storage: load_parquet() 加载历史 K 线
    RuleEngine->>Indicators: compute_all_indicators() 计算指标

    alt 多时间框架条件
        RuleEngine->>RuleEngine: load_mtf_data() 加载各 TF 数据
        RuleEngine->>RuleEngine: merge_to_base() 对齐到执行周期
    end

    loop 每个 entry_condition
        RuleEngine->>ValidateEngine: _evaluate_single_condition()
        ValidateEngine->>ValidateEngine: _resolve_subject() 解析主体
        ValidateEngine->>ValidateEngine: _resolve_target() 解析目标
        ValidateEngine-->>RuleEngine: 布尔序列
    end
    RuleEngine->>RuleEngine: AND/OR 逻辑组合 entry 条件 -> 触发信号

    loop 每个 exit_condition
        RuleEngine->>ValidateEngine: _evaluate_single_condition()
        ValidateEngine-->>RuleEngine: 布尔序列
    end
    RuleEngine->>RuleEngine: AND/OR 逻辑组合 exit 条件

    RuleEngine->>RuleEngine: 配对 entry/exit 信号 -> 交易记录
    RuleEngine->>RuleEngine: 统计胜率/平均回报
    RuleEngine-->>ValidateRoutes: RuleResult

    ValidateRoutes-->>Frontend: RuleValidateResponse

    Note over Frontend,ValidateRoutes: 旧版 WHEN/THEN 验证
    Frontend->>ValidateRoutes: POST /api/validate
    ValidateRoutes->>ValidateEngine: validate_hypothesis(when, then)

    ValidateEngine->>Storage: load_parquet() 加载数据
    ValidateEngine->>Indicators: compute_all_indicators()

    loop 每个 WHEN 条件
        ValidateEngine->>ValidateEngine: _evaluate_single_condition()
    end
    ValidateEngine->>ValidateEngine: AND 交集 -> 触发点

    loop 每个 THEN 条件
        ValidateEngine->>ValidateEngine: _evaluate_single_condition()
    end
    ValidateEngine->>ValidateEngine: 匹配统计 + 分布计算

    ValidateEngine-->>ValidateRoutes: ValidationResult
    ValidateRoutes-->>Frontend: ValidateResponse

    Note over Frontend,SceneEngine: 场景验证
    Frontend->>ValidateRoutes: POST /api/validate/scene
    ValidateRoutes->>SceneEngine: verify_scene()
    SceneEngine->>SceneEngine: 加载数据 + 计算指标
    SceneEngine->>SceneEngine: 场景检测器匹配
    SceneEngine->>SceneEngine: 前向统计计算
    SceneEngine-->>ValidateRoutes: SceneVerificationResult
```

## 数据转换规则
| 节点 | 输入 | 转换逻辑 | 输出 |
|------|------|----------|------|
| ValidateRoutes.run_rule_validation | RuleValidateRequest | 解析 entry/exit 条件组、调用 rule_engine | RuleValidateResponse |
| ValidateRoutes.run_validation | ValidateRequest | 解析 WHEN/THEN 条件组、调用 engine | ValidateResponse |
| RuleEngine.evaluate_rules | entry/exit conditions + 数据配置 | 加载数据 -> 计算指标 -> 逐条件评估 -> 信号配对 -> 统计 | RuleResult |
| ValidateEngine._evaluate_single_condition | condition dict + DataFrame | 解析 subject/action/target -> 布尔序列 | pd.Series (bool) |
| ValidateEngine._resolve_subject | subject str + DataFrame | 指标名/价格列/派生列 -> 对应 Series | pd.Series |
| ValidateEngine._resolve_target | target str + value | 数值/百分比/指标引用 -> 阈值 | float |
| 条件组合 | 多个布尔序列 + logic | AND: 全部为 True / OR: 任一为 True | 合并布尔序列 |
| 信号配对 | entry_signals + exit_signals | entry -> 最近的 exit 配对 -> 计算回报 | List[TradeRecord] |
| 统计聚合 | List[TradeRecord] | 胜率/平均回报/总回报/交易分布 | win_rate + avg_return + trades |

条件类型 (action):
- rises / falls: 指标值上升/下降
- crosses_above / crosses_below: 穿越阈值或其他指标
- above / below / equals: 与阈值比较
- in_zone: 在区间内

## 状态变迁链
假设验证为同步 HTTP 请求，无异步状态变迁:

```
请求到达 -> 数据加载 -> 指标计算 -> 条件评估 -> 信号配对 -> 统计计算 -> 响应返回
```

错误处理:
- 数据文件不存在 -> HTTP 404
- 条件格式无效 -> 跳过该条件 (warnings 记录)
- 指标计算失败 -> 跳过 (warnings 记录)
