## 校验 A（代码 ↔ 设计方案）

设计方案文件：`works/设计稿/预测性订单管理系统设计方案.md`

### 已落实
- P0 三层架构：OrderGenerator（价格计算）→ OrderManager（生命周期）→ Execution（账户执行）
- Order dataclass：order_id, side, price, size_pct, source, order_type(limit/market), predicted_range, fill_probability, status, bars_waiting
- compute_order_price：alpha = base + range * confidence，正态 CDF 成交概率
- OrderManager.manage：成交检查、信号反转取消、预测偏移取消、超时过期
- DecisionPipeline：observe→predict→manage→SL/TP→execute→evaluate 完整管线
- use_limit_orders 配置标志：False=legacy 市价，True=限价单路径
- SL/TP 执行价修正：SL 在触发价执行，TP 在目标价执行
- ReplayRunner：历史数据回放，复用 DecisionPipeline
- JudgmentConfig 扩展：pricing_alpha_base/range, min_fill_prob, order_max_wait_bars
- runner.py 重构：内联 K 线逻辑委托给 DecisionPipeline
