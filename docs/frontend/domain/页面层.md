# 页面层 (Pages)

## 职责与边界

**负责**：
- 承载各功能页面的顶层组件，组合 hooks / components / stores 构成完整页面视图
- 管理页面级局部状态（搜索条件、选中项、弹窗开关等）
- 通过路由状态 (`location.state`) 接收跨页面传参并驱动自动操作
- 统一处理加载骨架屏、空状态、错误提示等页面级 UX

**不负责**：
- 服务端数据获取逻辑（由 hooks 层封装）
- 全局 UI 状态管理（由 stores 层负责）
- 可复用 UI 呈现（由 components 层负责）

**边界**：页面层是用户可访问的最小路由单元。每个页面文件对应一个路由路径，内部可拆分子组件但只在本文件内使用。页面组件不直接调用 `api.ts`（DataManagement 的 datasets 列表查询除外），统一通过 React Query hooks 间接获取数据。

## 接口与契约

### 对外暴露的接口

| 接口 | 类型 | 签名 | 说明 |
|------|------|------|------|
| `Lab` | 页面组件 | `() => JSX.Element` | 策略实验室主页面，路由 `/lab` |
| `Evolution` | 页面组件 | `() => JSX.Element` | 进化中心主页面，路由 `/evolution` |
| `Strategies` | 页面组件 | `() => JSX.Element` | 策略库主页面，路由 `/strategies` |
| `Trading` | 页面组件 | `() => JSX.Element` | 模拟交易主页面，路由 `/trading` |
| `DataManagement` | 页面组件 | `() => JSX.Element` | 数据管理主页面，路由 `/data` |
| `Settings` | 页面组件 | `() => JSX.Element` | 设置主页面，路由 `/settings` |

### 对外暴露的数据结构

| 数据结构 | 类型 | 用途 |
|----------|------|------|
| 路由 state: `{ dna, symbol, timeframe, ... }` | 跨页面传参 | Lab 接收 DNA 回测参数，Trading 接收策略创建参数 |
| 页面内局部 state | `useState` | 搜索、筛选、弹窗开关、选中项等 UI 状态 |

## 模块依赖

| 依赖模块 | 依赖原因 |
|----------|----------|
| hooks | 获取服务端数据（useEvolution*, useStrategies*, useTrading*, useDatasets*, useValidation*, useChartIndicators） |
| components | 页面组装需要 GlassCard、PageTransition、EmptyState、ConfirmDialog 及各领域组件 |
| stores | Lab 页面使用 useLabStore / useChartSettings；Settings 页面使用 useChartSettings；AppLayout 使用 useAppStore |
| services/api | DataManagement 直接调用 `api.get("/api/data/datasets")` 查询数据集列表；Settings 直接调用 `api.get/put("/api/config")` 读写配置 |
| types | 各页面使用 Strategy、EvolutionTask、Dataset、DNA 等类型定义 |
| lib/constants | SYMBOL_OPTIONS、TIMEFRAME_SELECT_OPTIONS、LEVERAGE_OPTIONS、DIRECTION_OPTIONS 等选项常量 |
| lib/utils | cn()、formatCurrency()、formatPercent()、formatNumber() 格式化工具 |
