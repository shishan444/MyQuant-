# Zustand 状态管理 (Stores)

## 职责与边界

**负责**：
- 管理纯客户端 UI 状态（侧边栏折叠状态、图表指标配置、实验室表单配置）
- 持久化需要跨页面、跨会话保留的状态到 localStorage
- 提供 actions 修改状态，保持不可变更新模式

**不负责**：
- 服务端数据缓存和获取（全部由 React Query 管理）
- 全局认证状态（当前无认证模块）
- 路由状态（由 react-router 管理）

**边界**：Zustand stores 在本项目中严格限定为纯 UI 状态管理。设计意图是让 React Query 独占服务端数据层，Zustand 只管客户端本地状态。只有需要持久化或跨组件共享的 UI 配置才放到 store 中，页面内临时状态使用 useState。

## 接口与契约

### 对外暴露的接口

| 接口 | 类型 | 签名 | 说明 |
|------|------|------|------|
| `useAppStore` | Zustand Store | `() => AppState` | 全局应用状态 |
| `useLabStore` | Zustand Store | `() => LabState` | 实验室配置状态 |
| `useChartSettings` | Zustand Store | `() => ChartSettingsState` | 图表技术指标配置 |

#### useAppStore 接口

| 接口 | 签名 | 说明 |
|------|------|------|
| `sidebarCollapsed` | `boolean` | 侧边栏是否折叠 |
| `toggleSidebar` | `() => void` | 切换侧边栏折叠 |
| `setSidebarCollapsed` | `(collapsed: boolean) => void` | 设置侧边栏状态 |

#### useLabStore 接口

| 接口 | 签名 | 说明 |
|------|------|------|
| `config` | `LabConfig` | 实验室完整配置（交易对/周期/指标列表/评分模板/初始资金/手续费/滑点） |
| `setConfig` | `(updates: Partial<LabConfig>) => void` | 批量更新配置 |
| `addIndicator` | `(indicator: IndicatorConfig) => void` | 添加指标到列表 |
| `removeIndicator` | `(id: string) => void` | 从列表移除指标 |
| `updateIndicator` | `(id: string, updates) => void` | 更新指定指标配置 |
| `resetConfig` | `() => void` | 重置为默认配置 |

#### useChartSettings 接口

| 接口 | 签名 | 说明 |
|------|------|------|
| `emaList` | `EmaEntry[]` | EMA 配置列表（周期/颜色/启用状态） |
| `boll` | `BollConfig` | 布林带配置（启用/周期/标准差/颜色） |
| `rsi` | `RsiConfig` | RSI 配置（启用/周期/超买线/超卖线） |
| `vol` | `VolConfig` | 成交量配置（启用/位置：叠加或独立） |
| `addEma` | `(period: number) => void` | 添加 EMA（自动分配颜色） |
| `removeEma` | `(index: number) => void` | 移除指定 EMA |
| `updateEma` | `(index, updates) => void` | 更新 EMA 配置 |
| `reorderEma` | `(from, to) => void` | 调整 EMA 顺序 |
| `setBoll` | `(updates) => void` | 更新布林带配置 |
| `setRsi` | `(updates) => void` | 更新 RSI 配置 |
| `setVol` | `(updates) => void` | 更新成交量配置 |
| `resetToDefaults` | `() => void` | 恢复默认指标配置 |
| `getEmaPeriods` | `() => number[]` | 获取已启用的 EMA 周期列表 |
| `getBollParams` | `() => {period, std}` | 获取布林带参数 |
| `getIndicatorParams` | `() => ChartIndicatorConfig` | 获取完整指标配置（用于 API 请求和持久化） |

### 对外暴露的数据结构

| 数据结构 | 类型 | 用途 |
|----------|------|------|
| `EmaEntry` | `{period, color, enabled}` | 单条 EMA 配置 |
| `BollConfig` | `{enabled, period, std, color}` | 布林带配置 |
| `RsiConfig` | `{enabled, period, overbought, oversold}` | RSI 配置 |
| `VolConfig` | `{enabled, position: "overlay"\|"separate"}` | 成交量配置 |

## 模块依赖

| 依赖模块 | 依赖原因 |
|----------|----------|
| types/strategy | useLabStore 引用 IndicatorConfig、LabConfig 类型 |
| types/api | useChartSettings 引用 ChartIndicatorConfig 类型 |
| lib/constants | useChartSettings 引用 CHART_INDICATOR_DEFAULTS、EMA_DEFAULT_COLORS 构建默认值 |

## 持久化策略

| Store | localStorage Key | 持久化范围 |
|-------|-------------------|------------|
| useAppStore | `myquant-app` | 仅 sidebarCollapsed |
| useLabStore | 不持久化 | 每次刷新恢复默认值 |
| useChartSettings | `chart-indicator-settings` | 全量持久化（emaList / boll / rsi / vol） |
