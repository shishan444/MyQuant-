# 工具函数库 (Lib / Utils)

## 职责与边界

**负责**：
- 提供无状态、无副作用、纯函数的工具函数
- 管理全局常量定义（交易对选项、周期选项、指标列表、评分模板等）
- 实现领域特定的数据转换逻辑（DNA 生成、策略分类命名、进化图表数据转换）

**不负责**：
- 异步操作（不含 fetch / API 调用）
- UI 渲染（不含 React 组件）
- 状态管理（不含可变状态）

**边界**：lib 层是最底层的基础设施模块，所有函数均为纯函数或常量定义。不依赖任何 UI 框架或状态管理库，仅依赖 types 层的类型定义。

## 接口与契约

### 对外暴露的接口

#### lib/utils.ts -- 通用工具函数

| 接口 | 签名 | 说明 |
|------|------|------|
| `cn` | `(...inputs: ClassValue[]) => string` | className 合并工具（clsx + tailwind-merge） |
| `formatPercent` | `(value: number) => string` | 格式化百分比（0.05 -> "+5.0%"） |
| `formatCurrency` | `(value: number) => string` | 格式化货币（12345 -> "$12,345"） |
| `formatNumber` | `(value: number, decimals?) => string` | 格式化数字（保留指定小数位） |
| `formatPercentValue` | `(value: number) => string` | 格式化百分比值（5 -> "+5.0%"） |
| `formatDuration` | `(start: string, end: string) => string` | 格式化时间跨度（"3分钟"/"1.5小时"） |
| `formatDateTime` | `(t: string) => string` | 格式化日期时间（中文本地化） |

#### lib/dna-generator.ts -- DNA 生成器

| 接口 | 签名 | 说明 |
|------|------|------|
| `generateDnaFromValidation` | `(when, then, pair, timeframe) => DNA` | 将 WHEN/THEN 验证条件转换为 DNA 结构。映射规则：WHEN -> entry_trigger, THEN -> exit_trigger；action 映射为 condition type（gt/lt/cross_above/cross_below 等）；indicator 自动推断默认参数（RSI:14, EMA:20, MACD:12,26,9） |

#### lib/strategy-utils.ts -- 策略工具

| 接口 | 签名 | 说明 |
|------|------|------|
| `getStrategyType` | `(dna: DNA \| null) => string` | 根据 DNA 中首个 entry_trigger 的指标名称，查 INDICATOR_TYPE_MAP 返回策略分类（趋势/动量/波动/量价/混合） |
| `getStrategyName` | `(dna: DNA \| null) => string` | 生成策略自动命名，格式："{指标}{类型} {方向} {周期}"，如 "EMA趋势 做多 4H" |

#### utils/evolutionChart.ts -- 进化图表数据转换

| 接口 | 签名 | 说明 |
|------|------|------|
| `ChartDataPoint` | interface | 图表数据点（generation/bestScore/avgScore/cumulativeBest/isChampionChange/stagnationCount/population/isPopulationBoundary） |
| `ParsedDiagnostics` | interface | 解析后的诊断数据（avgTrades/diversity/population） |
| `ChartTransformResult` | interface | 转换结果（data/championChanges/boundaries/stats） |
| `parseDiagnostics` | `(top3Summary?) => ParsedDiagnostics` | 解析后端 pipe 分隔的 top3_summary 字符串（格式："best=85.2\|pop=2\|diag={...}"） |
| `transformChartData` | `(records) => ChartTransformResult` | 5 轮转换：原始映射 -> 种群边界检测 -> 累计最佳计算 -> 冠军变更检测 -> 停滞计数 |

### 对外暴露的数据结构

| 数据结构 | 类型 | 用途 |
