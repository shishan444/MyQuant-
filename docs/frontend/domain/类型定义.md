# TypeScript 类型定义 (Types)

## 职责与边界

**负责**：
- 定义前端全局共享的 TypeScript 类型和接口
- 提供后端 API 响应结构的类型契约
- 导出常量枚举（指标列表、周期选项等）

**不负责**：
- 运行时校验（不使用 Zod 等库，类型仅用于编译时检查）
- 业务逻辑（纯类型定义文件，不包含函数实现）
- 服务层内部类型（如 trading.ts 中的 TradingTask 在服务文件内定义并导出）

**边界**：types 层是前后端数据契约的前端侧表达。每个文件对应一个领域（api / strategy / chart / scene）。类型定义与后端 Pydantic model 一一对应，命名采用 snake_case 保持一致性。服务层内部的类型（trading.ts 的 TradingTask 等）由服务文件自行定义并导出，不放在 types 目录。

## 接口与契约

### 对外暴露的数据结构

#### api.ts -- 核心领域类型

| 数据结构 | 用途 |
|----------|------|
| `SignalGene` | 信号基因 -- 单个指标触发条件（indicator/params/role/field/condition） |
| `LogicGenes` | 逻辑基因 -- 入场/出场/加仓/减仓的逻辑组合（AND/OR） |
| `ExecutionGenes` | 执行基因 -- 交易对 + 周期 |
| `RiskGenes` | 风险基因 -- 止损/止盈/仓位/杠杆/方向 |
| `TimeframeLayerModel` | 多周期层模型 -- 单层的信号基因 + 逻辑基因 + 角色 |
| `DNA` | 策略 DNA -- signal_genes + logic_genes + execution_genes + risk_genes + layers（多周期）+ 元数据 |
| `Strategy` | 策略实体 -- strategy_id/name/dna/symbol/timeframe/source/metrics/tags/notes |
| `StrategyMetrics` | 策略指标 -- 年化收益/夏普/回撤/胜率/盈亏比/Sortino 等 |
| `BacktestResult` | 回测结果 -- 收益/夏普/回撤/胜率/交易数/总分/权益曲线/信号 |
| `TradeSignal` | 交易信号 -- buy/sell + 时间/价格/置信度/原因 |
| `EvolutionTask` | 进化任务 -- 任务配置 + 进度 + 冠军策略指标 |
| `EvolutionTaskStatus` | 任务状态枚举 -- pending/running/paused/stopped/completed |
| `EvolutionHistoryRecord` | 代际历史记录 -- generation/best_score/avg_score/top3_summary |
| `GenerationUpdate` | WS 代际更新消息 -- generation_complete/strategy_discovered 等 6 种 type |
| `DiscoveredStrategy` | 发现策略 -- 进化过程中自动提取的有效策略 |
| `EvolvedStrategy` | 进化策略 -- champion/snapshot 来源标记 |
| `Dataset` | 数据集实体 -- dataset_id/symbol/interval/row_count/quality_status |
| `OhlcvData` | OHLCV 数据 -- dataset_id + data 数组（timestamp/O/H/L/C/V） |
| `PaginatedResponse<T>` | 通用分页响应 -- items/total/page/page_size |
| `StrategyListResponse` | 策略列表响应 |
| `EvolutionTaskListResponse` | 进化任务列表响应 |
| `EvolutionHistoryResponse` | 进化历史响应 |
| `DatasetListResponse` | 数据集列表响应 |
| `ValidateRequest` | 假设验证请求 -- pair/timeframe/start/end/when/then |
| `ValidateResponse` | 假设验证响应 -- match_rate/triggers/distribution/percentiles |
| `ConditionInput` | 条件输入 -- subject/action/target/window/logic/timeframe |
| `RuleCondition` | 规则条件 -- logic(IF/AND/OR)/timeframe/subject/action/target |
| `RuleValidateRequest` | 规则验证请求 -- pair/timeframe/start/end/entry_conditions/exit_conditions |
| `RuleValidateResponse` | 规则验证响应 -- buy_signals/sell_signals/trades/win_rate |
| `ChartIndicatorConfig` | 图表指标配置 -- EMA 周期/颜色 + BOLL + RSI + VOL |
| `ChartIndicatorsResponse` | 图表指标 API 响应 -- EMA/BOLL/RSI/MACD/KDJ 数据 |
| `AvailableSource` / `AvailableSourcesResponse` | 可用数据源列表 |
| `TriggerRecord` | 验证触发记录 |
| `DistributionBucket` | 收益分布桶 |
| `MutationRecord` | 变异记录 |

#### strategy.ts -- 策略配置类型

| 数据结构 | 用途 |
|----------|------|
| `IndicatorConfig` | 指标配置 -- id/type/params/visible |
| `LabConfig` | 实验室配置 -- datasetId/symbol/timeframe/indicators/scoreTemplate/initCash/fee/slippage |
| `ScoreTemplate` | 评分模板类型 -- profit_first/steady/risk_first/custom |
| `INDICATOR_OPTIONS` | 常量 -- 可用指标列表（EMA/SMA/RSI/MACD 等 11 个） |
| `TIMEFRAME_OPTIONS` | 常量 -- 周期选项（1m/5m/15m/1h/4h/1d） |

#### chart.ts -- 图表类型

| 数据结构 | 用途 |
|----------|------|
| `OhlcvDataPoint` | OHLCV 数据点 -- timestamp/O/H/L/C/V |
| `ChartThemeConfig` | 图表主题 -- 背景色/网格色/蜡烛色/线条色 |
| `LegendItem` | 图例项 -- id/label/color/visible |
| `EquitySeries` | 权益曲线系列 -- name/color/data |
| `BollingerBandData` | 布林带数据 -- upper/middle/lower |
| `MTFIndicatorData` | 多周期指标数据 |
| `LegendGroup` | 图例分组 |

#### scene.ts -- 场景验证类型

| 数据结构 | 用途 |
|----------|------|
| `SceneTypeInfo` | 场景类型信息 -- id/label/description/group/parent |
| `SceneVerifyRequest` | 场景验证请求 -- symbol/timeframe/scene_type/params/horizons |
| `HorizonSummary` | 时间跨度统计 -- 触发数/胜率/平均收益/分布/百分位 |
| `SceneTriggerDetail` | 触发点详情 -- 时间/价格/指标快照/前瞻统计 |
| `SceneVerifyResponse` | 场景验证响应 -- 触发数/各跨度统计/触发详情 |
